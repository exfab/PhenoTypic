TukeyOutlierFraction
====================

Flag ``(group, time)`` bins with a high fraction of Tukey outliers.

Parameters and usage: :py:class:`TukeyOutlierFraction <phenotypic.analysis.TukeyOutlierFraction>`.

- **Written to:** the frame ``analyze()`` returns; a CLI run stores it as one table in ``deliverables/qc/qc.duckdb``
- **Columns:** 7

.. _measurement-info-quality-tukey:

:doc:`QUALITY_TUKEY </api_reference/api/phenotypic.schema.QUALITY_TUKEY>`
-------------------------------------------------------------------------

.. list-table:: Metric family: **QC_Tukey**
   :header-rows: 1
   :class: phenotypic-measurement-table

   * - Column
     - Description
     - Type
   * - ``QC_Tukey_LowerFence``
     - Lower Tukey fence, Q1 - k*IQR.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``QC_Tukey_UpperFence``
     - Upper Tukey fence, Q3 + k*IQR.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``QC_Tukey_NumOutliers``
     - Members falling outside the fences.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``QC_Tukey_NumMembers``
     - Members contributing to the statistic.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
