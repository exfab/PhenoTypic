.. _measurement-op-expectedvsdetectedcount:

ExpectedVsDetectedCount
=======================

Flag groups whose detected colony count diverges from metadata.

Parameters and usage: :py:class:`ExpectedVsDetectedCount <phenotypic.analysis.ExpectedVsDetectedCount>`.

- **Written to:** the frame ``analyze()`` returns; a CLI run stores it as one table in ``deliverables/qc/qc.duckdb``
- **Columns:** 6

.. _measurement-info-quality-count:

:doc:`QUALITY_COUNT </api_reference/api/phenotypic.schema.QUALITY_COUNT>`
-------------------------------------------------------------------------

.. list-table:: Metric family: **QC_Count**
   :header-rows: 1
   :class: phenotypic-measurement-table

   * - Column
     - Description
     - Type
   * - ``QC_Count_Detected``
     - Detected colony count in the group.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``QC_Count_Expected``
     - Expected colony count from the metadata frame.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``QC_Count_Delta``
     - Detected − Expected (signed; negative = missing).
     - :bdg-ref-secondary:`Quality <measurement-classification>`

-------------------------------------------------------------------------

Every quality check writes these columns; see :ref:`measurement-shared-columns`.

.. list-table:: Metric family: **QC**

   * - Column
     - Description
     - Type
   * - ``QC_Count_Flag``

     - Categorical: pass \| warn \| fail.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
