.. _measurement-op-relativemad:

RelativeMAD
===========

Flag ``(group, time)`` bins with poor robust agreement across replicates.

Parameters and usage: :py:class:`RelativeMAD <phenotypic.analysis.RelativeMAD>`.

- **Written to:** the frame ``analyze()`` returns; a CLI run stores it as one table in ``deliverables/qc/qc.duckdb``
- **Columns:** 6

.. _measurement-info-quality-mad:

:doc:`QUALITY_MAD </api_reference/api/phenotypic.schema.QUALITY_MAD>`
---------------------------------------------------------------------

.. list-table:: Metric family: **QC_MAD**
   :header-rows: 1
   :class: phenotypic-measurement-table

   * - Column
     - Description
     - Type
   * - ``QC_MAD_Median``
     - Group median of the measurement.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``QC_MAD_MAD``
     - Median absolute deviation (raw, before normalization).
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``QC_MAD_NumMembers``
     - Members contributing to the statistic.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
