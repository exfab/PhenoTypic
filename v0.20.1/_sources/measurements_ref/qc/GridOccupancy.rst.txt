.. _measurement-op-gridoccupancy:

GridOccupancy
=============

Flag groups whose grid occupancy (filled cells / expected) is low.

Parameters and usage: :py:class:`GridOccupancy <phenotypic.analysis.GridOccupancy>`.

- **Written to:** the frame ``analyze()`` returns; a CLI run stores it as one table in ``deliverables/qc/qc.duckdb``
- **Columns:** 6

.. _measurement-info-quality-occupancy:

:doc:`QUALITY_OCCUPANCY </api_reference/api/phenotypic.schema.QUALITY_OCCUPANCY>`
---------------------------------------------------------------------------------

.. list-table:: Metric family: **QC_Occupancy**
   :header-rows: 1
   :class: phenotypic-measurement-table

   * - Column
     - Description
     - Type
   * - ``QC_Occupancy_Filled``
     - Distinct grid cells holding at least one colony (doublets count once).
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``QC_Occupancy_Expected``
     - Expected grid-cell count from the metadata frame (rows per group).
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``QC_Occupancy_Vacant``
     - Expected - Filled; empty/missing grid cells in the group.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
