LinearLagModel
==============

Linear-with-softplus lag-phase growth fitter (no saturation).

Parameters and usage: :py:class:`LinearLagModel <phenotypic.analysis.LinearLagModel>`.

- **One row per:** fitted group (the ``groupby`` columns)
- **Written to:** the frame ``analyze()`` returns; when it is the pipeline's model, a CLI run writes ``deliverables/LinearLagModel.csv`` and ``.parquet``
- **Columns:** 11, each a pattern (see Placeholders)

.. rubric:: Placeholders

Some column names depend on how you run the operation. They are shown as patterns, with these placeholders:

``<metric>``
   The fitted column without its metric-family prefix: fitting ``Size_Area`` writes ``LinearLagModel_Area_v``.
