phenotypic.gui.results_viewer.timeline_view package#

Results-viewer Timeline tab — overlay matrix over OutputRoot.master_df axes.

Renders the shared timeline engine (gui/_shared/timeline) + the focus-and-navigate timeline.js controller over the run’s overlay PNGs, with a (row × time) axis pair drawn from OutputRoot.master_df (spec §6/§16).

phenotypic.gui.results_viewer.timeline_view.build_timeline_records(output_root: OutputRoot, df: DataFrame, *, row_col: str, time_col: str) → list[dict[str, object]][source]#

Build build_matrix records from a filtered master slice.

One record per (dataset, stem) pair surviving df that has an overlay PNG on disk. row_value/time_value are the row’s values in row_col/time_col (stringified so they match build_matrix’s own str(...) axis coercion downstream).

Parameters:

  • output_root (OutputRoot) – The viewer’s output handle (overlay membership lookup).

  • df (DataFrame) – The filtered master mirror (the active filter slice).

  • row_col (str) – Y-axis column name.

  • time_col (str) – X (time)-axis column name.

Returns:

A list of {"row_value", "time_value", "cell_ref": (dataset, stem)} dicts. cell_ref is the (dataset, stem) tuple consumed by the thumbnail + DZI routes.

Return type:

list[dict[str, object]]

phenotypic.gui.results_viewer.timeline_view.selectable_time_columns(df: DataFrame, column_value_sets: Mapping[str, list[str]]) → list[str][source]#

Return columns eligible as the timeline X (time) axis.

A column is eligible iff it is NOT measurement-prefixed and NOT Object_Label, AND either its name matches a Metadata_Time-like pattern OR its dtype is numeric/temporal. There is no cardinality cap (spec §15.2). Metadata_* time-like names sort first, then everything else, alphabetically within each bucket.

Parameters:

  • df (DataFrame) – The frame to inspect (typically the filtered master mirror).

  • column_value_sets (Mapping[str, list[str]]) – Unused for eligibility but accepted for signature symmetry with selectable_axis_columns (callers thread the same pair through). Cardinality is intentionally NOT consulted.

Returns:

Eligible time-column names in bucketed sort order.

Return type:

list[str]
