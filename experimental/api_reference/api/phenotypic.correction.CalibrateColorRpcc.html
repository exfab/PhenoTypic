Bases: ImageCorrector, PlotImage

Fit and apply a root-polynomial correction from this frame’s own chart.

Best For:

  • Plate photographs with a colour-checker card mounted in the frame, where every image can calibrate itself.

  • Multi-session studies where a stored profile would carry a stale exposure: a same-image fit absorbs the gain, a transferred one cannot.

  • Unattended batches, where the quality gate must refuse a frame rather than emit a correction fitted to an obscured card.

Consider Also:

  • ColorCorrector when a fitted ColorCheckerProfile already exists and only needs applying.

  • ColorCheckerProfile directly when the chart is free-standing and fully visible rather than part of the scene.

  • DenoiseBlockMatch afterwards: correction improves accuracy while mildly amplifying per-pixel noise.

Parameters:

  • rois (Annotated[list[CheckerRoi], MinLen(min_length=1)]) – Rectangles to look inside, one per card region. Required. Accepts CheckerRoi objects or plain [row_min, col_min, row_max, col_max] sequences (regionprops bbox order), mixed freely. The rectangle is all that is declared: how many tiles it holds and which chart patch each one is are recovered from the pixels.

  • checker_type (str) – Key in colour.CCS_COLOURCHECKERS.

  • target_illuminant (str) – Working illuminant. Reference values are Bradford-adapted from the chart’s own illuminant to this one before any comparison.

  • degree (Annotated[int, TuneSpec(low=None, high=None, step=None, log=False, categories=None, tunable=False)]) – Root-polynomial degree. Fixed for every image in a run; never adapted to what a frame happened to detect. Correcting two frames of one experiment with different degrees puts a reproducible bias into the contrast between them.

  • grid (tuple[int, int] | None) – Optional (nrows, ncols) of each card’s tile block, used only when fitting a lattice from scratch. Says nothing about which patches are present.

  • lattice_prior (list[CheckerLattice] | None) – Per-ROI lattices from an earlier frame. When given, they are refined onto this frame rather than re-fitted.

  • refine_method (Literal['rigid', 'frozen']) – "rigid" (reference-free, default) or "frozen". ECC registration is not offered: it needs a reference band shipped with every serialised pipeline.

  • core_trim (Annotated[float, TuneSpec(low=0.2, high=0.6, step=None, log=False, categories=None, tunable=True)]) – Fraction trimmed from each tile box before measuring. 0.4 keeps the central 60 % of each axis, which is where the detector’s residual error is absorbed.

  • medoid_candidates (Annotated[int, Ge(ge=1)]) – Candidate-set size for the deterministic medoid.
