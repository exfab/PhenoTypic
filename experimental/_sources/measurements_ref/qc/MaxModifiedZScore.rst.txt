.. _measurement-op-maxmodifiedzscore:

MaxModifiedZScore
=================

Flag ``(group, time)`` bins whose worst member is a robust outlier.

Parameters and usage: :py:class:`MaxModifiedZScore <phenotypic.analysis.MaxModifiedZScore>`.

- **Written to:** the frame ``analyze()`` returns; a CLI run stores it as one table in ``deliverables/qc/qc.duckdb``
- **Columns:** 6

.. _measurement-info-quality-zmax:

:doc:`QUALITY_ZMAX </api_reference/api/phenotypic.schema.QUALITY_ZMAX>`
-----------------------------------------------------------------------

.. list-table:: Metric family: **QC_ZMax**
   :header-rows: 1
   :class: phenotypic-measurement-table

   * - Column
     - Description
     - Type
   * - ``QC_ZMax_Median``
     - Group median of the measurement.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``QC_ZMax_MAD``
     - Median absolute deviation used to scale the modified Z-score.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``QC_ZMax_NumMembers``
     - Members contributing to the statistic.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
