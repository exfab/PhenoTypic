STUDY_METADATA
==============

Python export: ``phenotypic.schema.STUDY_METADATA``

Recommended ``MetadataStudy_*`` tags for the REMBI Study component.

One set per run (title, authors, license, …). Mirrors REMBI's Study field
names. Members render as ``MetadataStudy_<Label>`` (e.g.
``MetadataStudy_Title``). Structured REMBI lists (authors/publications/links)
are flattened to scalar tags whose value may be a delimited string.
Recommended vocabulary, not a validator.

.. list-table:: Category: **MetadataStudy**
   :header-rows: 1

   * - Column label
     - Description
     - Type
   * - ``MetadataStudy_Title``
     - Study title.
     - :bdg-ref-muted:`Identity / design <measurement-classification>`
   * - ``MetadataStudy_Description``
     - Free-text study description.
     - :bdg-ref-muted:`Identity / design <measurement-classification>`
   * - ``MetadataStudy_PrivateUntilDate``
     - Embargo date until which the study stays private.
     - :bdg-ref-muted:`Identity / design <measurement-classification>`
   * - ``MetadataStudy_Keywords``
     - Keywords describing the study.
     - :bdg-ref-muted:`Identity / design <measurement-classification>`
   * - ``MetadataStudy_Author``
     - Study author(s); delimited string when multiple.
     - :bdg-ref-muted:`Identity / design <measurement-classification>`
   * - ``MetadataStudy_License``
     - Data license (e.g. CC0, CC-BY-4.0).
     - :bdg-ref-muted:`Identity / design <measurement-classification>`
   * - ``MetadataStudy_Funding``
     - Funding statement or grant reference(s).
     - :bdg-ref-muted:`Identity / design <measurement-classification>`
   * - ``MetadataStudy_Publications``
     - Associated publication(s) or DOI(s).
     - :bdg-ref-muted:`Identity / design <measurement-classification>`
   * - ``MetadataStudy_Links``
     - Related links or external resource URLs.
     - :bdg-ref-muted:`Identity / design <measurement-classification>`
   * - ``MetadataStudy_Acknowledgements``
     - Acknowledgements text.
     - :bdg-ref-muted:`Identity / design <measurement-classification>`
