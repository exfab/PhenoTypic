.. _measurement-shared-columns:

Shared columns
==============

Columns that no single operation owns: they sit on every row, or on every table of one kind. Each is documented once, here.

On every measurement row
------------------------

Every row of ``deliverables/measurements.csv`` says which colony it describes and where that colony is. The pipeline adds the ten bounding-box columns to every row itself, whether or not :doc:`../measure/MeasureBounds` is in your pipeline; they are documented on that page (:ref:`measurement-info-bbox`). The image bookkeeping columns are on :doc:`../metadata/index`.

.. _measurement-info-object:

:doc:`OBJECT </api_reference/api/phenotypic.schema.OBJECT>`
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. list-table:: Metric family: **Object**
   :header-rows: 1
   :class: phenotypic-measurement-table

   * - Column
     - Description
     - Type
   * - ``Object_Label``
     - Integer label uniquely identifying each detected object (colony) within its source image. Acts as the per-image primary key shared by every measurement table, letting all per-colony measurements be joined together and traced back to a single colony on the agar plate.
     - :bdg-ref-muted:`Identity / design <measurement-classification>`

.. _measurement-info-grid:

:doc:`GRID </api_reference/api/phenotypic.schema.GRID>`
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Written on rows from a ``GridImage`` only.

.. list-table:: Metric family: **Grid**
   :header-rows: 1
   :class: phenotypic-measurement-table

   * - Column
     - Description
     - Type
   * - ``Grid_RowNum``
     - Zero-based row number, from 0 at the top, of the grid cell that holds the colony's centroid (the mean position of its pixels). A colony whose centroid lies outside the grid is assigned to the nearest edge row.
     - :bdg-ref-muted:`Identity / design <measurement-classification>`
   * - ``Grid_ColNum``
     - Zero-based column number, from 0 at the left, of the grid cell that holds the colony's centroid (the mean position of its pixels). A colony whose centroid lies outside the grid is assigned to the nearest edge column.
     - :bdg-ref-muted:`Identity / design <measurement-classification>`
   * - ``Grid_RowMajorIdx``
     - Zero-based number of the colony's grid cell, counted left to right along each row and then down the rows. It is RowNum × (number of grid columns) + ColNum. Row major is the standard in most programming and data science array libraries. Used for indexing into 2D arrays.
     - :bdg-ref-muted:`Identity / design <measurement-classification>`
   * - ``Grid_ColMajorIdx``
     - Zero-based number of the colony's grid cell, counted top to bottom down each column and then across the columns. It is ColNum × (number of grid rows) + RowNum. Lab automation logic uses column-major (column-wise) indexing for well plate operations because 96-well plates are physically arranged with 8 rows (labeled A-H) and 12 columns (numbered 1-12), and this layout maps directly to how multichannel pipettes operate.
     - :bdg-ref-muted:`Identity / design <measurement-classification>`

With a metadata file
--------------------

.. _measurement-info-metadata-match:

:doc:`METADATA_MATCH </api_reference/api/phenotypic.schema.METADATA_MATCH>`
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Written only when a run is given ``--metadata``. True on a row that comes from the metadata file alone, with no detected colony.

.. list-table:: Metric family: **QC**
   :header-rows: 1
   :class: phenotypic-measurement-table

   * - Column
     - Description
     - Type
   * - ``QC_MetadataOnly``
     - True on a row that comes only from the metadata file: a listed well (or other metadata row) where no colony was detected. Its measurement cells are empty, not zero, and both an empty well and a colony that detection missed produce such a row. It is False on every row that carries a measured colony.
     - :bdg-ref-secondary:`Quality <measurement-classification>`

On every quality check table
----------------------------

.. _measurement-info-quality-check:

:doc:`QUALITY_CHECK </api_reference/api/phenotypic.schema.QUALITY_CHECK>`
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

``<name>`` is the check's ``name``: ``ICC`` writes ``QC_ICC_Metric`` and ``ExpectedVsDetectedCount`` writes ``QC_Count_Metric``.

.. list-table:: Metric family: **QC**
   :header-rows: 1
   :class: phenotypic-measurement-table

   * - Column
     - Description
     - Type
   * - ``QC_<name>_Flag``
     - True when the metric crosses fail_threshold in the bad direction; eligible for curation.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``QC_<name>_Metric``
     - Headline metric, a dimensionless ratio, fraction or score (for example MAD / \|median\|); the bad direction is set by the check's _HIGHER_IS_BAD flag. Drives Status.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``QC_<name>_Status``
     - Categorical: pass \| warn \| fail.
     - :bdg-ref-secondary:`Quality <measurement-classification>`

On every growth model table
---------------------------

.. _measurement-info-model-metrics:

:doc:`MODEL_METRICS </api_reference/api/phenotypic.schema.MODEL_METRICS>`
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

``<metric>`` is the fitted column without its metric-family prefix: fitting ``Size_Area`` writes ``ModelMetrics_Area_MAE``.

.. list-table:: Metric family: **ModelMetrics**
   :header-rows: 1
   :class: phenotypic-measurement-table

   * - Column
     - Description
     - Type
   * - ``ModelMetrics_<metric>_MAE``
     - Mean absolute difference between the fitted curve and the data points it was fitted to.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``ModelMetrics_<metric>_MSE``
     - Mean squared difference between the fitted curve and the data points it was fitted to.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``ModelMetrics_<metric>_RMSE``
     - Typical distance between the fitted curve and the data points it was fitted to, as the square root of the mean squared difference.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``ModelMetrics_<metric>_R2``
     - Share of the variation in the fitted data points that the curve explains: 1 is a perfect fit, and 0 or below is no better than the points' mean. It is the coefficient of determination, and NaN for a group with two or fewer points.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``ModelMetrics_<metric>_NumSamples``
     - Number of data points the model was fitted to, after any points the fitter drops (such as post-saturation time points).
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``ModelMetrics_<metric>_OptimizerLoss``
     - Final value of the cost that the fitting optimizer minimized. It is the cost of scipy's least_squares: half the sum of the robust loss ρ applied to each squared residual, including any weighting or regularization terms the model adds.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``ModelMetrics_<metric>_OptimizerStatus``
     - Integer code from scipy's least_squares saying why the fit stopped: 0 when it reached the evaluation limit and 1 to 4 when a convergence tolerance was met. It is NaN when the fit failed.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
