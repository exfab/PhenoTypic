LinearCapAndLagModel
====================

Linear-softplus growth fitter with a softplus saturation ceiling.

Parameters and usage: :py:class:`LinearCapAndLagModel <phenotypic.analysis.LinearCapAndLagModel>`.

- **One row per:** fitted group (the ``groupby`` columns)
- **Written to:** the frame ``analyze()`` returns; when it is the pipeline's model, a CLI run writes ``deliverables/LinearCapAndLagModel.csv`` and ``.parquet``
- **Columns:** 14, each a pattern (see Placeholders)

.. rubric:: Placeholders

Some column names depend on how you run the operation. They are shown as patterns, with these placeholders:

``<metric>``
   The fitted column without its metric-family prefix: fitting ``Size_Area`` writes ``LinearCapAndLagModel_Area_v``.

.. list-table:: Metric family: **LinearCapAndLagModel**
   :header-rows: 1
   :class: phenotypic-measurement-table

   * - Column
     - Description
     - Type
   * - ``LinearCapAndLagModel_<metric>_v``
     - The post-lag phase growth rate.
     - :bdg-ref-success:`Tier 1 · Direct phenotype <measurement-tiers>`
   * - ``LinearCapAndLagModel_<metric>_s0``
     - The initial size
     - :bdg-ref-success:`Tier 1 · Direct phenotype <measurement-tiers>`
   * - ``LinearCapAndLagModel_<metric>_lambda``
     - The duration of the lag phase
     - :bdg-ref-success:`Tier 1 · Direct phenotype <measurement-tiers>`
   * - ``LinearCapAndLagModel_<metric>_alpha``
     - lag phase transition sharpness
     - :bdg-ref-primary:`Tier 2 · Descriptive trait <measurement-tiers>`
   * - ``LinearCapAndLagModel_<metric>_smax``
     - Carrying capacity used by the model. Either the user-provided scalar or the per-group observed maximum.
     - :bdg-ref-success:`Tier 1 · Direct phenotype <measurement-tiers>`
   * - ``LinearCapAndLagModel_<metric>_beta``
     - Saturation transition sharpness. Fitted per-group when a saturation shoulder is detected and ``beta`` is ``None`` at construction; held at the user-provided scalar (or the module default) when no shoulder is present.
     - :bdg-ref-primary:`Tier 2 · Descriptive trait <measurement-tiers>`
   * - ``LinearCapAndLagModel_<metric>_mode``
     - Fit variant selected per-group: 'fixed_beta' (beta held at the user-provided or module-default value) or 'fitted_beta' (beta fitted as a 5th free parameter when a saturation shoulder is detected).
     - :bdg-ref-secondary:`Quality <measurement-classification>`

:doc:`MODEL_METRICS </api_reference/api/phenotypic.schema.MODEL_METRICS>`
-------------------------------------------------------------------------

Every growth model writes these columns; see :ref:`measurement-shared-columns`.

.. list-table:: Metric family: **ModelMetrics**
   :header-rows: 1
   :class: phenotypic-measurement-table

   * - Column
     - Description
     - Type
   * - ``ModelMetrics_<metric>_MAE``
     - Mean absolute difference between the fitted curve and the data points it was fitted to.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``ModelMetrics_<metric>_MSE``
     - Mean squared difference between the fitted curve and the data points it was fitted to.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``ModelMetrics_<metric>_RMSE``
     - Typical distance between the fitted curve and the data points it was fitted to, as the square root of the mean squared difference.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``ModelMetrics_<metric>_R2``
     - Share of the variation in the fitted data points that the curve explains: 1 is a perfect fit, and 0 or below is no better than the points' mean. It is the coefficient of determination, and NaN for a group with two or fewer points.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``ModelMetrics_<metric>_NumSamples``
     - Number of data points the model was fitted to, after any points the fitter drops (such as post-saturation time points).
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``ModelMetrics_<metric>_OptimizerLoss``
     - Final value of the cost that the fitting optimizer minimized. It is the cost of scipy's least_squares: half the sum of the robust loss ρ applied to each squared residual, including any weighting or regularization terms the model adds.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
   * - ``ModelMetrics_<metric>_OptimizerStatus``
     - Integer code from scipy's least_squares saying why the fit stopped: 0 when it reached the evaluation limit and 1 to 4 when a convergence tolerance was met. It is NaN when the fit failed.
     - :bdg-ref-secondary:`Quality <measurement-classification>`
