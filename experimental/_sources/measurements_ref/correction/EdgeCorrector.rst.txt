EdgeCorrector
=============

Analyzer for detecting and correcting edge effects in arrayed colony growth.

Parameters and usage: :py:class:`EdgeCorrector <phenotypic.analysis.EdgeCorrector>`.

- **Written to:** the frame ``analyze()`` returns only; a CLI run does not write it to a file
- **Columns:** 2, each a pattern (see Placeholders)

.. rubric:: Placeholders

Some column names depend on how you run the operation. They are shown as patterns, with these placeholders:

``<column>``
   The corrected column in full: correcting ``Size_Area`` writes ``EdgeCorrection_NewVal-Size_Area``.

.. _measurement-info-edge-correction:

:doc:`EDGE_CORRECTION </api_reference/api/phenotypic.schema.EDGE_CORRECTION>`
-----------------------------------------------------------------------------

.. list-table:: Metric family: **EdgeCorrection**
   :header-rows: 1
   :class: phenotypic-measurement-table

   * - Column
     - Description
     - Type
   * - ``EdgeCorrection_Cap-<column>``
     - Ceiling applied to the measurement in this group: the mean of the top_n largest values among fully surrounded (interior) colonies at the last time point. When the group is not corrected it is the group's maximum, so nothing is clipped.
     - :bdg-ref-info:`Derived <measurement-classification>`
   * - ``EdgeCorrection_NewVal-<column>``
     - The measurement after edge correction: each value in the group clipped to between 0 and Cap, or the original value when the group is not corrected.
     - :bdg-ref-info:`Derived <measurement-classification>`
