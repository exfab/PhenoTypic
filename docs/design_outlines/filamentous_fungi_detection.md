# Filamentous Fungi Detection Pipeline -- Presenter's Notes

## Terminology

| Term | Plain-English Meaning |
|------|-----------------------|
| **Thresholding** | Deciding for each pixel: "is this bright enough to be fungus, or is it background?" Everything above the cutoff is kept; everything below is discarded. |
| **Otsu / Triangle thresholding** | Two automatic methods for choosing the brightness cutoff. Otsu splits the histogram into two groups minimising overlap; Triangle draws a line along the histogram shape and picks the cutoff where the gap is largest. Neither requires manual tuning. |
| **Hysteresis thresholding** | Uses two cutoffs instead of one: a strict "definitely fungus" threshold and a lenient "maybe fungus" threshold. Maybe-pixels are only kept if they physically connect to a definite pixel. Good for tracing faint structures that are continuous with bright ones. |
| **Morphological opening / closing** | Shape-based clean-up. Opening (erode then dilate) removes small specks and debris. Closing (dilate then erode) bridges small gaps and fills tiny holes. Think of it as sanding off bumps vs. filling cracks. |
| **Mask** | A black-and-white version of the image where white = "detected as fungus" and black = "background." Used to mark which pixels belong to colonies. |
| **Label map / labelled image** | Like a mask, but instead of just white/black, each distinct object gets its own unique number (colony 1, colony 2, ...). This is how the software tracks which pixels belong to which colony. |
| **Gaussian blur** | Smooths the image by averaging each pixel with its neighbours, weighted by a bell curve. A large blur radius produces a smooth "background" image; subtracting it removes slow illumination gradients while preserving small objects. |
| **Convolution / kernel** | Sliding a small template (kernel) across the image, computing a weighted sum at each position. Different kernels detect different things -- edges, blobs, lines, etc. |
| **Fourier / frequency domain** | A way of decomposing an image into spatial frequencies: low frequencies are broad gradients (illumination), high frequencies are fine detail (edges, hyphae). Filtering in this domain lets you selectively suppress or boost different scales of structure. |
| **Phase congruency** | A measure of local image structure based on how well different frequency components align (are "in phase") at each pixel. Unlike raw brightness, it detects edges and lines reliably even at very low contrast. |
| **Anisotropy** | How directional a local region is. A hypha running left-to-right has high anisotropy (strong direction); a round blob or uniform background has low anisotropy (no preferred direction). |
| **Distance transform** | Replaces each pixel's value with its distance to the nearest object. Used to create elevation surfaces for watershed and to measure gaps between structures. |
| **Watershed** | Treats the image (or distance surface) as a topographic landscape. "Water" floods uphill from seed points (inocula); where two floods meet is a boundary between colonies. |
| **Dijkstra's algorithm** | A shortest-path algorithm from graph theory. Here, each pixel is a node and the cost to cross it depends on how un-hyphal it looks. The algorithm finds the cheapest route from a colony to a fragment through the gap. |
| **Cost surface** | An image-sized map where each pixel's value represents how expensive it is to traverse. Low cost = looks like a hypha (easy to cross); high cost = looks like empty background (hard to cross). |
| **Skeletonisation** | Thins a shape down to a one-pixel-wide centreline while preserving its connectivity. Used to extract representative paths through colony branches for calibration. |
| **Signal-to-noise ratio (SNR)** | How much brighter a structure is compared to its immediate surroundings. A high SNR means the path clearly stands out from background; a low SNR means it may just be noise. |
| **IQR (interquartile range)** | The range between the 25th and 75th percentile of a set of values. Used as a robust measure of spread for setting quality thresholds -- less sensitive to extreme outliers than standard deviation. |
| **BM3D** | Block-matching and 3D filtering. A denoising algorithm that finds similar small patches across the image and averages them collectively to remove noise while keeping real detail. |
| **Laplacian-of-Gaussian (LoG)** | A blob detector. Smooths the image at a specific scale, then computes the second derivative (Laplacian). Responds strongly to round objects whose size matches the smoothing scale. Running it at multiple scales finds blobs of different sizes. |
| **Gaussian mixture model (GMM)** | A statistical model that assumes the data is generated by a mixture of bell curves. Used here to separate the bright core of an inoculum from its dimmer surround by fitting two overlapping distributions to pixel intensities within each detected region. |

## The Core Problem

Filamentous fungi grow as a network of thin branching hyphae radiating from a
central inoculation point. Under a camera, these hyphae are:

1. **Faint** -- thin and semi-transparent, often barely above background noise.
2. **Fragmented** -- simple thresholding catches some segments but misses
   others, producing disconnected blobs instead of a continuous network.
3. **Entangled** -- neighboring colonies' hyphae can overlap or grow close
   together, making it unclear which branch belongs to which colony.

The pipeline addresses each of these in sequence.

---

## Pipeline Overview

| Step | Algorithm | Purpose |
|------|-----------|---------|
| 1 | Variance-stabilized BM3D denoising | Remove camera sensor noise |
| 2 | Homomorphic filtering | Even out plate illumination |
| 3a | Multi-scale blob detection | Find the central inoculation plugs |
| 3b | Dual-mask branch detection | Detect hyphal structures (fragmented) |
| 3c | Distance-weighted watershed | Assign detected pixels to colonies |
| 3d | Dijkstra shortest-path reconnection | Trace orphaned fragments back to colonies |

---

## Step 1: Variance-Stabilized BM3D Denoising

Camera sensors introduce two kinds of noise -- a baseline electronic hum
(Gaussian) and shot noise proportional to signal brightness (Poisson).
Together they create speckle that can look like, or obscure, fine hyphae.

A generalised Anscombe transform first stabilises the noise, making it
uniform across bright and dim areas. Then BM3D (block-matching and 3D
filtering) groups similar small patches across the image and averages them in
a transform domain to suppress noise while preserving real edges. This is done
before any detection so that downstream steps do not mistake noise for hyphae
or miss real hyphae buried in noise.

## Step 2: Image Enhancement

### Homomorphic filtering (pipeline level)

Separates the illumination component (slow spatial variation from the light
source) from the reflectance component (the actual plate surface) by working
in the log-frequency domain. Suppresses illumination gradients while
preserving local contrast, so colony intensity is directly comparable across
the plate.

### Phase congruency (inside the detector)

The key enhancement for filaments. Instead of looking at absolute pixel
brightness, phase congruency detects locations where Fourier components across
multiple spatial scales are maximally in phase -- these correspond to edges
and lines regardless of contrast. Hyphae show up as thin line-like structures
with strong phase congruency even when their absolute brightness is low.

This produces three feature maps used later for reconnection:

- **Energy** -- how "structured" each pixel is.
- **Orientation** -- the local direction of structure at each pixel.
- **Anisotropy** -- how elongated/directional the structure is (hyphae are
  highly anisotropic; blobs are not).

## Step 3a: Inoculum Detection

Finds the dense central plugs where fungi were spotted onto the plate. The
sub-pipeline is:

1. **Gaussian background subtraction** -- subtracts a heavily blurred copy of
   the image to remove large-scale illumination gradients while preserving
   small round objects.
2. **Median filtering** -- suppresses salt-and-pepper noise without blurring
   edges.
3. **Multi-scale Laplacian-of-Gaussian blob enhancement** -- convolves the
   image with LoG kernels at multiple radii spanning the expected inoculum
   size range. Each kernel responds maximally to blobs matching its radius;
   the per-pixel maximum across scales highlights round objects regardless of
   exact size.
4. **Contrast stretching and morphological smoothing** -- normalises dynamic
   range and removes small noise artefacts.
5. **Peak detection** -- thresholds the enhanced image and identifies local
   maxima corresponding to inoculum centres.
6. **Gaussian mixture model core extraction** (optional) -- fits a two-component
   GMM per detected region to separate the bright core from the diffuse
   surround, refining boundaries for inocula with fuzzy edges.

The result is a set of labelled inoculum regions that serve as colony seeds
for all subsequent assignment.

## Step 3b: Fragmented Detection (Dual-Mask Approach)

Rather than relying on a single threshold, the detector builds two independent
masks and combines them:

### Mask A -- Gaussian-subtracted thresholding

Subtracts a Gaussian-blurred background, then applies Triangle automatic
thresholding (fits a line from the histogram peak to the tail and finds the
point of maximum distance). Morphological opening removes small debris;
morphological closing bridges small gaps. This catches the broader, more
obvious structures but may include noise blobs.

### Mask B -- Phase congruency with hysteresis thresholding

Takes the phase congruency energy map and applies dual-threshold hysteresis:
pixels above a strict "definite" threshold (Otsu) are accepted unconditionally;
pixels above a permissive "maybe" threshold (Triangle) are accepted only if
they connect to a definite pixel. This is more selective and catches thin
filaments that Mask A may miss.

### Consensus filtering

Only keeps Mask A regions that have any pixel overlap with Mask B. Noise blobs
from Mask A are eliminated (they will not appear in both methods) while real
structures detected by either method are retained.

The result is still fragmented -- disconnected blobs of detected fungal
material with gaps between them.

## Step 3c: Distance-Weighted Watershed Assignment

Each detected pixel needs to be assigned to a colony. A Euclidean distance
transform from the inoculum regions creates an elevation surface -- each
inoculum sits at elevation zero (deepest basin) and the surface rises with
distance. A watershed flood then expands outward from each inoculum through
the detected mask. Boundaries form where two floods meet at equidistant
points from their respective inocula.

This keeps branches with their origin colony: the origin flood fills a branch
from its base (low elevation, near inoculum) before a neighbor's flood can
reach the branch tip.

After this step:

- **Central regions** -- blobs overlapping a known colony's inoculum are
  assigned to that colony.
- **Fragments** -- blobs with no inoculum overlap remain unassigned orphans.

## Step 3d: Why Reconnection Is Needed

The orphan fragments are real hyphal material (they passed both detection
masks) but the gap between them and the nearest colony was too faint or thin
to be detected by thresholding. Without reconnection, colony extent is
undercounted -- measured area includes only the bright central mass and misses
distal hyphae.

## Step 3e: Dijkstra Shortest-Path Reconnection

The reconnection treats the image as a weighted graph where the traversal cost
of each pixel reflects how un-hyphal that pixel looks.

### Cost surface construction

The composite cost at each pixel combines four phase-congruency-derived
signals:

| Signal | High cost means... |
|--------|--------------------|
| Phase congruency energy | Featureless background (low energy = high cost) |
| Anisotropy | No directional structure (isotropic = high cost) |
| Orientation coherence | Neighbouring pixels point in different directions (incoherent = high cost) |
| Median absolute deviation of intensity | Noisy or textured, not structured (high MAD = high cost) |

Already-assigned colony pixels are set to near-zero cost so the search
passes through known structure freely.

Additional penalties are applied for pixels near the plate edge (border
penalty) and for gaps between colonies (distance-gap penalty) to discourage
paths through empty background.

### Dijkstra shortest-path search

From every colony boundary pixel simultaneously, Dijkstra's algorithm floods
outward through the cost surface. Each fragment is assigned to whichever
colony can reach it via the cheapest total path -- i.e., the colony connected
by the most hyphal-looking corridor through the gap.

A radial penalty factor discourages paths that retreat toward the inoculum,
encoding the biological prior that hyphae grow outward.

### Pre-screening

Before running the full shortest-path search, fragments are pre-screened by
comparing their local cost to a calibrated threshold derived from the cost
statistics at known colony boundaries. Fragments sitting in regions of
uniformly high cost (deep background) are discarded early, saving computation.

### Quality filtering

Not every traced path is real. The algorithm calibrates quality thresholds by
skeletonising known-good colony branches and measuring their path statistics,
then rejects reconnection paths that are significantly worse. Filters check:

- **Sliding-window cost** -- is the path consistently low-cost along its
  length, or does it cross a high-cost gap?
- **Signal-to-noise ratio** -- is the path brighter than its immediate
  surroundings?
- **Phase congruency energy** -- does the path follow actual image structure
  or cross featureless background?

Strictness is controlled by an IQR-based multiplier: higher values accept
more borderline paths, lower values are more conservative.

### Tiled processing

Large plate images are split into overlapping square tiles and each tile is
processed independently, then merged. This keeps memory usage bounded for
high-resolution scans.

### Final re-assignment

After reconnection paths are painted into the label map, a second
distance-weighted watershed pass re-assigns all pixels (including newly
connected ones) to ensure consistent colony boundaries.

## Measurements (post-detection)

| Algorithm | What it tells you |
|-----------|-------------------|
| Grid spatial statistics | Colony positions relative to the plate grid -- spacing, regularity, which well each colony occupies |
| Shape descriptors | Per-colony morphology -- area, perimeter, circularity, eccentricity (how round vs elongated) |
| Intensity statistics | Per-colony brightness -- mean, median, standard deviation of pixel values within each colony |
| Haralick texture features | Surface texture -- captures whether colony surfaces are smooth, rough, wrinkled, etc. |

## Limitations and Caveats

### Colony separation in dense plates

The watershed boundary between two colonies is purely geometric -- it falls at
the midpoint between their inocula. When hyphae from adjacent colonies
physically overlap or intertwine in the gap zone, there is no way to determine
from a single top-down image which hyphae belong to which colony. The boundary
is an approximation; measured area near colony edges may include material from
the neighbour.

### Inoculum assumptions

Inoculum detection assumes roughly circular, well-separated spots within a
known size range. Irregularly shaped inocula (e.g., streaks, merged spots, or
very diffuse liquid deposits) may be missed or split into multiple detections.
If the inoculum step fails, all downstream assignment fails with it.

### Contrast dependence

Despite phase congruency being contrast-invariant in theory, the dual-mask
detection and thresholding steps still require some minimum contrast between
hyphae and background. Extremely faint hyphae on a noisy background -- or
hyphae growing on pigmented media that closely matches hyphal colour -- may
fall below detection thresholds entirely.

### Reconnection is gap-limited

Dijkstra reconnection can bridge gaps where there is residual image structure
(faint hyphae below detection threshold but still visible in the phase
congruency energy map). It cannot bridge gaps across truly featureless
background -- if a hypha is completely invisible in the image, no cost-surface
path will find it. Very long gaps are also penalised, so widely separated
fragments may not reconnect even if faint structure exists.

### Single time-point

The pipeline processes each image independently. It does not track colony
growth over time, so it cannot use temporal continuity to resolve ambiguous
detections. Time-lapse analysis would require external tracking logic on top
of per-frame results.

### Computational cost

BM3D denoising and phase congruency are both computationally expensive,
especially on high-resolution plate scans. The tiled Dijkstra search adds
further cost proportional to the number of orphan fragments. Processing a
single high-resolution plate image can take minutes rather than seconds.

### Flat colony morphologies

The pipeline is designed for filamentous growth (branching hyphae radiating
from a centre). Flat, homogeneous colony morphologies (e.g., bacterial lawns,
smooth yeast colonies) lack the directional structure that phase congruency
and anisotropy exploit. For these morphologies, simpler detection methods are
more appropriate.

### Media and imaging artefacts

Condensation on the plate lid, scratches on the agar surface, printing or
markings on the plate, and reflections from the light source can all produce
image structures that resemble hyphae in the phase congruency domain. The
dual-mask consensus filtering removes some of these, but persistent artefacts
that appear in both masks will be retained as false detections.
