Pick a pipeline.json.pht-pipe (or legacy .json) — its operations define what can be tuned. Or come straight from the Builder via "Tune this pipeline", or Open spec… to re-edit a saved one.

library: .phenotypic-gui/presets/tune/

Config files are JSON, type-tagged by suffix — pipelines .pht-pipe, tuning specs .pht-tune (legacy .json still loads). Specs save to your sandbox library .phenotypic-gui/presets/tune/ by default, or Browse… anywhere. Each is stamped with the phenotypic version that wrote it, so loading an old spec on a newer build warns on mismatch. Deploy separately writes the run's own copy to deliverables/tuning_spec.json.pht-tune.
