# A08 sanitized handoff

The production implementer receives a generated no-`.git` export, never this oracle worktree. The
complete A08 allowlist is `CLEAN_ROOM_ALLOWLIST.txt`.

The fixture contains project-authored inputs and source-generated numeric arrays, but no source
text. It records border and dilation state, four raw and robust openings, ranks and observed
orientation indices, intensity, split costs, selected high-class size and orientations, correction
signs and vectors, normalized source direction, per-scale intensity and direction, merged output,
and winning scale.

The executable's two plateau-sensitive raw arrays are not production expectations. `CONTRACT.md`
names them and freezes deterministic paper semantics. Source direction arrays are observations;
public direction is emitted only under the contract's unique-direction predicate.

All other A08-specific material and all private artifacts are forbidden. Before implementation, the
assigned clean-room agent must record its identity and attest that it received only the generated
export by completing `CLEAN_ROOM_ATTESTATION.md`.
