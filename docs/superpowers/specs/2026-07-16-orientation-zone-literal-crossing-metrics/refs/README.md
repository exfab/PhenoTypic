# Local reference manifest

This folder records the reference-acquisition status for the orientation-zone
literal-crossing aggregate-metric specification.

Sen's 1968 paper, “Estimates of the Regression Coefficient Based on Kendall's
Tau” (*JASA* 63(324), DOI `10.1080/01621459.1968.10480934`), was located through
the publisher and a Pacific Climate Impacts Consortium mirror. The publisher
blocked automated download with HTTP 403 and the mirror failed TLS verification
in this environment, so no local reference copy is claimed.

The design therefore uses the median pairwise-slope estimator as conceptual
inspiration and independently specifies and validates the exact formula. It is
not an exact transcription or behavioral port of Sen's implementation.
