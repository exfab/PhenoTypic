How each reference-free segmentation metric actually works

Twenty-two algorithms, each with its definition, a mechanism diagram, the formula's variables, and what the output number reads as. Ordered by family: what is built today, then the classic region statistics, the object/spatial family, the bio-imaging family, and the learned predictors.

Built today — the four ReferenceFreeScorer terms

Each is fixed-normalized to [0,1] higher-is-better with hard external bounds; the base scorer complements each into cost. Fixed bounds — not min–max over the swept grid — is the deliberate defence against the Böck instability (card 11).

ShapeRegularity

BUILT🟢 direct

Averages the shape priors a correctly-segmented colony should satisfy. Reads the public Shape_* schema columns only — it never recomputes geometry from the mask, so it costs nothing beyond frame arithmetic.

Inputmeasurement frame only
Costvery low — no image access
FamilyC.2 morphology prior
Output metric
Value
mean(Solidity, Circularity, 1−Eccentricity), each clamped to [0,1]
Range
[0, 1] — higher is better
Reads as
near 1 = round, convex, compact colonies; falling = merged pairs (solidity), shattered fragments (circularity), or smeared/elongated blobs (eccentricity)
Variables & guards
A, A_hull
colony area and its convex-hull area
P
perimeter of the colony contour
min_area
drops tiny colonies — perimeter metrics are unreliable at a few pixels
_clamp01
defends against solidity > 1 on the synthetic plate

Contrast — Otsu separation η

BUILT🟢 direct

The one built term that scores the mask against the image it came from: it reads image.gray and image.objmask, splits the grayscale into foreground and background, and asks what fraction of total variance the split explains.

Inputgrayscale image + binary objmask
Costvery low — one pass
FamilyA.3 Otsu criterion
Output metric
Value
η = σ²_B / σ²_T, with σ²_B = w(1−w)(μ_fg − μ_bg)²
Range
[0, 1] — higher is better; already normalized, no grid dependence
Reads as
fraction of grayscale variance the mask explains. Returns 0 for a degenerate all-foreground or all-background mask, and for a zero-variance image
Variables
w
foreground fraction, mask.mean()
σ²_T
total grayscale variance (constant for the image)
σ²_B
between-class variance; maximizing it ≡ minimizing within-class

Blind spot: histogram-only. A salt-and-pepper mask ties a clean one at the same gray split — it must be paired with a spatially aware term (busyness, Zeboudj, or Q).

SizeCV

BUILT🟢 direct

Replicate colonies of one strain should be about the same size. Computes the coefficient of variation of Size_Area inside each replicate group, averages across groups, then folds the result into a bounded score.

Inputmeasurement frame + a grouping key
Costvery low
FamilyC.3 replicate homogeneity
Output metric
Value
1 / (1 + mean_groups(σ/μ)) over Size_Area
Range
(0, 1] — higher is better
Reads as
near 1 = replicates agree on size; falling = the segmenter is splitting or merging inconsistently within a group that should be uniform
Variables & choices
σ
sample sd (ddof=1) — a replicate group is a sample, not a population
groups
replicate_groupby; unset treats the whole frame as one group
n = 1
single-colony group contributes CV = 0 (perfectly uniform)

Count — expected vs detected

BUILT🟢 direct

The most colony-specific signal available, and nearly supervised for free: the plate layout already declares how many colonies each group should have. Optional — the term only appears when a count_check is configured from a metadata path.

Inputmeasurement frame + layout CSV
Costvery low
Shared withQCScorer, SupervisedScorer count tier
Output metric
Value
t = exp(−ln2 · m / fail_threshold), m = |detected − expected| / expected
Range
[0, 1] — higher is better
Reads as
1 = exact count match; 0.5 = exactly at the configured failure bar; → 0 as the count diverges. An unmatched group gives m = ∞ → 0
Variables
m
relative count divergence, in [0, ∞)
fail_threshold
the check's own hard-fail value; the half-score anchor

Family A — classic region statistics

The 1980s–90s standalone evaluation functions. Every one is the same trade: interior homogeneity against control of over-segmentation. None is implemented here. Provenance note: the catalogue flags these formulas as mechanism-verified but not symbol-verified — re-derive from the primary source before coding one.

Levine & Nazif U + contrast

A.1🟡 redefine

The conceptual template every later metric descends from: score a segmentation by a performance vector of gray-level uniformity inside regions and disparity across adjacent ones.

Inputlabelled regions + adjacency graph
Costlow, plus adjacency construction
SourceLevine & Nazif 1985
Output metric
Value
U (uniformity) and cᵢ (contrast) — a vector, not one scalar
Range
U ∈ [0,1], higher = more uniform; contrast higher = better separated
Reads as
colony interiors should be flat (high U) and stand off the agar (high contrast); area weighting suppresses specks
Variables
e²(Rⱼ)
squared gray-level error of region j
Wⱼ, Z
per-region weight and normalizer — both unspecified/heuristic
pᵢⱼ
shared boundary length between adjacent regions

Failure mode: free weights are undefined; textured regions read as non-uniform; and there is no over-segmentation penalty at all.

Weszka–Rosenfeld busyness

A.2🟢 direct

Counts how often the image crosses between object and background. A clean mask crosses rarely; a speckled or ragged one crosses constantly. Lower is better.

Inputgrayscale + a threshold value
Costvery low — one co-occurrence pass
SourceWeszka & Rosenfeld 1978
Output metric
Value
busyness — fraction of object↔background adjacencies
Range
[0, 1] — lower is better (invert before use as goodness)
Reads as
low = smooth compact blobs; high = ragged, speckled, noise-shattered masks
Variables
C_gl(i,j)
original gray level at pixel (i,j)
L(i,j)
the thresholded/segmented level; discrepancy = ∑(C_gl − L)

Why it fits colonies: arrayed colonies are compact, weakly-textured blobs on smooth agar — the exact regime busyness was built for. But it only evaluates threshold-type algorithms, and it is global, not per-region.

Liu & Yang F

A.4🔴 weak

The original goodness function: region colour error penalized by a region-count term. Historically important as the baseline F′ and Q were built to fix. Smaller is better.

Inputlabelled regions + colour image
Costvery low
SourceLiu & Yang 1994
Output metric
Value
F(I) = √N · ∑ⱼ( e²ⱼ / √Sⱼ )
Range
[0, ∞) — smaller is better; the published /1000·S_I form does not change ranking
Reads as
region error traded against a count penalty — but the trade is mis-tuned
Variables
N
number of regions
Sⱼ
area of region j
e²ⱼ
squared colour error of region j

Documented bias toward over-segmentation. And for arrayed plates it is doubly wasteful: the region count is already known (rows × cols), so the built Count term exploits it far better than a blind √N.

Borsotti F′ and Q

A.5🟢 direct

The consensus best of the F-family, and the catalogue's pick for the single most directly reusable classic metric. Q is the only one here that penalizes both failure directions at once. Smaller is better.

Inputlabelled regions + image
Costlow; needs an area histogram
SourceBorsotti, Campadelli & Schettini 1998
Output metric
Value
Q(I) = (√N / 1000·S_I) · ∑ⱼ[ e²ⱼ/(1+log Sⱼ) + (N(Sⱼ)/Sⱼ)² ]
Range
[0, ∞) — smaller is better
Reads as
rises when colonies merge and when they shatter — the two colony failure modes, scored by one number
Variables
N(Sⱼ)
how many regions share region j's exact area
S_I
total image area; 1000 is arbitrary scaling
e²ⱼ
squared colour error of region j

Brittleness: the same-area terms depend on exact area coincidences, so they are sensitive to quantization. And Q can misrank when correct colonies genuinely vary in size — which they do across a growth timecourse.

Zeboudj contrast C(I)

A.6🟢 direct

The best-balanced classic single score for colonies: it couples interior uniformity and boundary separation into one normalized number, and unlike Otsu it is spatially aware. Higher is better.

Inputregions + boundary extraction
Costlow, plus boundary tracing
SourceZeboudj 1988 — untraceable PhD thesis
Output metric
Value
C(I), area-weighted mean of per-region C(Rᵢ)
Range
[0, 1] — higher is better
Reads as
near 1 = flat colony interiors with sharp agar contrast at the rim; falling = smeared boundaries or internally noisy masks
Variables & cases
c(s,t)
|I(s)−I(t)| / (L−1) pixel contrast
Iᵢ / Eᵢ
mean max-neighbour contrast inside / across the boundary
edge case
C = Eᵢ when Iᵢ = 0; C = 0 otherwise — a discontinuity

Provenance flag: the primary source is an untraceable 1988 PhD thesis — every published form is second-hand. The max-of-neighbours is also noise-sensitive, and texture reads as non-uniform (barely bites on low-texture plates).

Entropy metric E

A.7🟡 redefine

The one genuinely parameter-free classic: no magic 1000, no free weights. An MDL/coding-theory argument balances region uniformity against region count. Smaller is better.

Inputlabelled regions + luminance
Costvery low
SourceZhang, Fritts & Goldman (CVIU survey)
Output metric
Value
E = H_ℓ(I) + H_r(I)
Range
[0, ∞) — smaller is better
Reads as
low = each colony mask is intensity-uniform without the plate being shattered into fragments
Variables
H(Rⱼ)
luminance entropy within region j
H_r
∑ (Sⱼ/S_I)·H(Rⱼ) — expected region entropy
H_ℓ
−∑ (Sⱼ/S_I)·log(Sⱼ/S_I) — layout entropy

Blind spot: layout entropy depends only on the size distribution, not spatial arrangement — two segmentations with identical size histograms but totally different layouts tie. Pair it with a contrast term.

Family B — object & spatial statistics

The GEOBIA/remote-sensing lineage. These operate on objects rather than pixels and bring spatial autocorrelation into the score. One of them carries the most important transfer caveat in the whole survey.

Global Score — and why not to use it

B.1–B.3🔴 avoid

Area-weighted variance (intra) plus Moran's I (inter), each min–max normalized over the tested set and summed. The normalization is the flaw, and it is specifically fatal for a tuning engine that is a grid sweep.

Inputsegments + source bands + RAG
Costmedium — adjacency graph
SourceEspíndola 2006; Johnson & Xie 2011; Böck 2017
Output metric
Value
GS = v_norm + I_norm, v = ∑aᵢσᵢ² / ∑aᵢ
Range
[0, 2] — lower is better, but the scale is grid-dependent
Reads as
uninterpretable in isolation; only comparable within one fixed candidate set
The remedy
fixed bounds
normalize against theoretical / single-pixel / whole-image extremes
natural range
Moran's I ∈ [−1,1]; q ∈ [0,1] — no rescaling needed
rank fusion
Mahalanobis or rank-based combination instead of min–max

Already defended against. Every built ReferenceFreeScorer term is fixed-normalized for exactly this reason. The caveat also reaches fANOVA: importances computed over grid-dependent scores inherit the same instability.

q-statistic

B.5 / B.9🟢 direct

The catalogue's pick for the cleanest single reference-free "is this partition good?" score for colonies: the fraction of total pixel-intensity variance the segmentation explains. Bounded by construction, so no normalization gymnastics.

Inputlabelled strata + intensity
Costlow — no adjacency graph
SourceGao et al. (geographical detector)
Output metric
Value
q = 1 − (within-strata SS / total SS)
Range
[0, 1] — higher is better; naturally bounded, grid-independent
Reads as
fraction of variance explained by the colony partition — the same reading as R² in a one-way ANOVA
Variables
h, k
stratum index and pixel index within it
Āₕ
mean intensity of stratum h
d_M
Gao fuses q with |Moran's I| by Mahalanobis distance to the worst-case point (1,0)

Caveat on Gao's fusion: the covariance Σ is still estimated from the tested set, so the Mahalanobis combination only partly escapes the Böck problem. q alone does escape it.

FGS — WV + DTNP

B.7🟢 direct

Replaces Moran's-I-over-a-region-adjacency-graph with a far cheaper trick: compare each object to the ring around its own bounding box. No adjacency graph at all.

Inputobjects + image; no RAG
Costlow — the point of the method
SourceZhao et al.
Output metric
Value
FGS = normalized homogeneity (WV) + normalized heterogeneity (DTNP)
Range
lower is better — but inherits GS-style normalization, so fix the bounds
Reads as
uniform colony interiors that also differ strongly from the agar immediately around them
Variables
aᵢ, vᵢ
object area and mean per-band variance
d
bounding-box enlargement, 1 px in the paper — tune to the colony gap

Transcription flag: the catalogue records that the DTNP closed form (Eqs. 4–5) was not fully transcribed — only the bounding-box-ring mechanism was verified from full text.

UOA — under/over-segmentation aware

B.6🟢 direct

The only metric here that tells you which way a segmentation is wrong, and where. Local and per-segment rather than one global scalar — arguably more useful for colonies than any single number.

Inputsegments + neighbourhood + a δ
Costhigh — per-segment neighbourhood analysis
SourceTroya-Galvis et al.
Output metric
Value
UOA_∑ (weighted sum) or UOA_L2 (L2 of the two components)
Range
lower is better; the per-segment scores are the useful output
Reads as
a per-colony diagnosis: this one is a merged doublet, that one is a split fragment — directly actionable for refinement
Variables
H
pluggable homogeneity: variance, entropy, contrast, Lab contrast, GLCM texture
δ
homogeneity threshold — the one tuned meta-parameter

Why colonies suit it: "merged doublet" and "split colony" are the two colony failure modes, and the grid supplies an expected colony size to set δ from. The authors' own caveat: all six tested H indices correlate with segment size.

EVI — edge validity index

B.8🟡 redefine

Asks a question no other family here asks: does the mask boundary actually sit on a real intensity edge? Missing from the whole GS/FGS lineage, and cheap to add.

Inputmask contours + an edge map
Costlow if the edge map already exists
SourceYu et al. (SAR), one of three terms in G
Output metric
Value
EVI — boundary/edge-map agreement, one of GHO + GHE + EVI → G
Range
higher is better
Reads as
high = the mask rim coincides with a genuine intensity transition; low = the boundary was placed by morphology, not by evidence
Local hook
edge map
PhenoTypic already computes Sobel/Laplace/Frangi/Sato/Meijering/phase responses in enhance/_focus_edge_* — an EVI term could reuse one directly

Take the idea, not the pipeline. Yu's Gamma/speckle machinery is SAR-specific and overkill here, but its three-term design — homogeneity + heterogeneity + explicit edge validity — is the most complete template in family B.

Family C — bio-imaging

Metrics built for cells rather than natural images. These are the closest to the domain — and the place where an assumption mismatch does the most damage, because two of them fail quietly rather than loudly.

CSE coverage metrics

C.1🟢 direct

The transferable half of Chen & Murphy's suite — the only peer-reviewed, fully reference-free cell-segmentation quality package. These ask whether the masks cover the right amount of the right stuff, using no marker channels at all.

Inputimage + instance masks
Costmedium
SourceChen & Murphy, MBoC 34(6):ar50, 2023
Output metrics that transfer
FFC
fraction of image foreground occupied by cells — transfers almost verbatim
NC
objects per 100 µm² — needs a physical pixel size, and the µm² scale is wrong for mm-scale colonies
Others
1−FBC, FCF, and 1/(ln CSSD + 1) — the last already approximated by the built SizeCV
Validation
vs F1
mean Pearson r = 0.83
vs Avg F1
r = 0.81
vs SEG′
r = 0.72

The recommended addition. FFC is cheap, peer-reviewed, fully reference-free, and orthogonal to all four built terms — none of which notices a colony that was missed entirely.

CSE uniformity family

C.1🔴 blocked

The other half of the suite — and the trap. These measure marker-expression uniformity within inferred cell types. On a single-channel plate they do not error; they return numbers that mean nothing.

Blocked byno marker panel on an RGB/gray plate
Also needsa paired nucleus-mask channel (FMCN)
MetricsACVF, FPCF, ACVC, FPCC, AS
The shipped overall score
Not closed-form
exp(PC1·evr₁ + PC2·evr₂) over a hardcoded StandardScaler and 2-component PCA
Fit on
637 multichannel tissue images (CODEX / Cell DIVE / MIBI / IMC), evr [0.573, 0.143] for 2Dv1.5
Refit path
sanctioned — both entry points accept a user-supplied PCA_model; the authors ship a separate cultured-cell refit

Do not pip-install and point it at a plate. Port the coverage subset deliberately and refit the PCA; running the packaged score wholesale produces plausible, meaningless output with nothing failing to tell you.

Cellpose flow error

C.7🟡 redefine

The most conceptually transferable per-instance confidence in the survey: a model checking its own output for self-consistency. Genuinely reference-free — the function signature takes no ground-truth argument at all.

Wheredynamics.py:292, current main (Cellpose 4.x)
Costlow — runs at inference
Scope2D only; skipped in 3D
Output metric
Value
flow error, per-label mean squared error — inverse polarity, not a probability
Gate
flow_threshold = 0.4 — a hard upper bound; remove_bad_flow_masks deletes anything above it
Reads as
low = the mask agrees with the model's own dense prediction; high = an artefact the model would not have drawn
Transfer blocker
needs
a model emitting a dense per-pixel field to disagree with
excludes
Otsu, watershed, hysteresis — no field, no self-consistency check
separate
cellprob_threshold (default 0.0) is the probability-like gate

The local analogue already exists. detect/nn/_dinosam2_detector.py computes cosine-to-prototype proposal scores, uses them as an accept/reject gate, then discards them. Persisting those is this idea, for the detector you actually have.

Family D — learned quality predictors

Instead of hand-designing a proxy, learn the map from (image, mask) to quality. All three are reference-free at inference; they differ entirely in what they need at build time.

Reverse Classification Accuracy

D.1–D.2🔴 reject

A genuinely clever trick: treat the prediction as if it were ground truth, train a segmenter on it, and see how well that segmenter does on images you do have labels for. Reference-free at test time — but not annotation-free overall.

Needsan annotated reference database
Cost~11 min/case (8-core i7 3.6 GHz)
SourceValindria et al., IEEE TMI 36(8):1597–1606, 2017
Why it is rejected here
Aggregate
looks excellent — 99% binary accuracy on 400 degraded segmentations; 95% on 4,805 UKBB scans; r ∈ [0.95, 0.99]
But
on complex-shaped and already-high-quality masks it systematically under-predicts DSC: threshold accuracy collapses to 0.454 (RF) and 0.051 (CNN) for LV myocardium
Fatal because
well-imaged agar plates are the near-perfect-mask regime — it would be blind exactly where the data lives
Variants & residual use
Conformal RCA
adds 1−α coverage intervals, but needs a second annotated calibration set and under-covers under domain shift
Still useful as
an offline label generator to bootstrap a regressor
✗ refuted
In-Context RCA speedups (0.70 s / 0.37 s) — killed 1–2, do not cite

Learned Dice regression

D.3🟡 med–high

Skip the reverse classifier entirely and regress quality directly: feed the image and its candidate masks to a CNN and have it output the predicted Dice. Four orders of magnitude faster than RCA.

Needsa large annotated corpus at train time
Cost40 ms GPU — >10,000× faster than RCA
SourceRobinson et al., MICCAI 2018 (LNCS 11073)
Output metric
Value
predicted DSC, a scalar per case
Accuracy
MAE 0.031 (SD 0.035), TPR 0.975, FPR 0.060, acc 0.965 at a DSC threshold of 0.7
Reads as
a direct stand-in for the overlap you cannot measure — usable as a pass/fail gate or a continuous objective
Authors' own limits
learns
features specific to the segmenter it was trained on
blind to
“small regional or boundary differences” — cannot assess fine-scale quality
watch
the split is at segmentation-sample level over 16,100 segmentations from 4,882 subjects — subject leakage likely

Degrade-and-train

D.4🟢 direct

The route that fits PhenoTypic best, because it manufactures its own labels. Take clean masks, corrupt them in known ways, and you have a supervised training set whose true overlap is known exactly — with no annotation at all.

Needsclean masks to corrupt — load_synth_yeast_plate()
Costlow at inference; build cost is the corruption set
SourceGaldran et al. (vessel segmentation)
Why this is the recommended learned route
No annotation
the label is a by-product of the corruption, not a human
Dual use
the same corpus unblocks the meta-validation gate — known Dice is exactly what _proxy_gt_spearman needs to correlate against
Colony-specific
corruptions must be colony error modes: erode, dilate, merge, split, drop, edge halos, debris — not generic noise
Risks
realism
synthetic corruptions must resemble real detector failures, or the regressor learns the wrong manifold
topology
transfer from synthetic to real plate topology is unproven
