Reference-free segmentation quality: what we have, what exists, what to add

Four metrics are implemented and currently dormant. Roughly thirty more are catalogued in-repo but unbuilt. A fresh literature pass adds five concrete candidates from the cell- and bio-imaging side — and rules one popular route out.

1 — What is implemented today

All four live in ReferenceFreeScorer (src/phenotypic/tune/score/_reference_free_scorer.py). Every term is fixed-normalized to [0,1] higher-is-better; the base scorer complements each into cost.

Mean of the per-colony shape priors that a well-segmented colony should satisfy. Reads the public schema columns only — never recomputes geometry from the mask.

Contrast

builthigh

Otsu between-class separation of foreground vs. background grayscale. The only term that scores the mask against the image it came from — it reads image.gray and image.objmask.

η = σ²B / σ²T,  σ²B = w(1−w)(μfg−μbg)²
Key
w
foreground fraction, mask.mean()
σ²T
total grayscale variance
FamilyA.3 Otsu criterion
CostVery low, one pass
Fails onHistogram-only — blind to spatial layout; degenerate all-fg/all-bg → 0

SizeCV

builthigh

Within-replicate size uniformity. Coefficient of variation of Size_Area computed inside each replicate group, averaged, then folded to a bounded score. Sample sd (ddof=1) — a replicate group is a sample, not a population.

score = 1 / (1 + meangroups(σ/μ))
FamilyC.3 replicate homogeneity
CostVery low
Fails onReal biological size variation; needs a grouping key

Count optional

builthigh

Expected-vs-detected grid count, reused verbatim from QCScorer when a path-configured count_check is supplied. Anchored so that hitting the check's own fail_threshold scores exactly 0.5.

t = exp( −ln2 · m / fail_threshold ),  m = |det − exp| / exp
FamilyC.6 arrayed-colony count QC
CostVery low
Fails onNeeds a layout CSV; inf when a group has no metadata counterpart

⚠ The scorer is dead code in production

availability() fails safe to False until meta_validate() passes — but both of its dependencies are declared structural stubs carrying TODO(DEFERRED-WORK §1):

  • _load_gt_masks() → returns {} whenever a path is configured
  • _proxy_gt_spearman() → returns 0.0

So the gate always abstains and the engine silently degrades to QCScorer (count-only). The ρ ≥ 0.7 enable / ≥ 0.8 unattended thresholds are also annotated in-code as engineering inference, not a cited cutoff.

Cellpose flow error

newmed

Genuinely reference-free per-instance self-consistency: recompute flow gradients from the predicted label image, take per-mask MSE against the network's own predicted field, discard masks above threshold. The function signature takes no ground-truth argument at all.

RCA — ruled out

reject

Aggregate numbers look excellent (95–99% accuracy, r ∈ [0.95, 0.99]). But there is a sharp documented failure on complex-shaped and already-high-quality masks, where it systematically under-predicts Dice.

4 — Traps

Four ways this goes wrong quietly, and one claim that did not survive verification.

The Böck normalization trap

Min–max-over-the-tested-set normalization (Espíndola / Johnson Global Score) makes the argmin depend on the parameter grid you happen to sweep — fatal for a tuning engine that is a grid sweep.

PhenoTypic already dodges this: every ReferenceFreeScorer term is fixed-normalized with hard external bounds. Keep it that way — and note it also constrains fANOVA importances, which inherit the same instability if the scores are grid-dependent.

CSE fails silently on single-channel input

functions.py::cell_type() runs k-means on an (n_cells × n_channels) matrix. With one channel the metrics degrade silently rather than erroring — the first-PC explained-variance ratio becomes trivially 1.0.

Pip-install it, point it at a plate, and it returns plausible numbers that mean nothing. It also requires the mask input to carry both a cell-mask and a nucleus-mask channel.

RCA fails where your data lives

The collapse is specifically on already-good masks. A metric that is accurate on bad segmentations and blind on good ones is the wrong shape for well-imaged plates, where nearly every mask is already good.

CellProfiler polarity is contradictory

The Methods in Molecular Biology chapter says a lower power-spectrum slope means more blur; CellProfiler's own docs say “a higher slope indicates … more blur”. It also gives opposite directions for FocusScore vs LocalFocusScore.

Re-derive every sign convention from measureimagequality.py before wiring any threshold.

✗ Refuted — do not cite

“In-Context RCA reduces cost to 0.70 s (UniverSeg) / 0.37 s (SAM 2), i.e. ~85× and ~162× faster than classical RCA.” Killed 1–2 in adversarial verification. The direction of that work — replacing per-test-image training with in-context segmentation — is real; the specific speedups are not verified here.

Domain transfer is untested throughout

Every quantitative result on this page comes from 3D cardiac MR, multiplexed tissue microscopy, or fluorescence cell imaging. No cited source evaluates any of these metrics on binary or instance colony masks on agar plates. MAE 0.03, r = 0.83, 11 min/case, flow_threshold = 0.4 — all domain-specific, all must be re-derived locally.

Two source-version discrepancies worth knowing: Chen & Murphy's published MBoC version and its bioRxiv v4 preprint report different benchmark correlations (0.81 Avg F1 vs 0.86 PRAUC), and the shipped 2Dv1.5 PCA (14 metrics) could not be confirmed identical to the paper's 10-metric model.

5 — What to do next

Ordered by value per unit of work.

  1. Unblock the meta-validation gate — nothing else matters until it does. ReferenceFreeScorer cannot be reached in production while _load_gt_masks() returns {}. The route is already the catalogued one: degrade load_synth_yeast_plate() masks with colony-specific corruptions (erode / dilate / merge / split / drop), which gives known Dice for free, then run the Spearman + argmax gate against it. The same corpus later trains a Galdran-style regressor.
  2. Add FFC (foreground occupancy) as a fifth term. Cheap, fully reference-free, peer-reviewed, and orthogonal to the four existing terms. Note SizeCV already approximates CSE's 1/(ln CSSD + 1), so that one is redundant.
  3. Persist the DINOSAM2 proposal scores. Free per-colony confidence that is already being computed and thrown away. No new algorithm.
  4. Drop RCA as an objective. The near-perfect-mask collapse plus 11 min/case rules it out. Keep it only in mind as an offline label generator.
  5. Do not pip-install CSE and run it on plates. The multichannel family fails silently rather than loudly. Port only the coverage subset, and refit the PCA.

Open question worth a dedicated pass

What is the cheapest colony-domain analogue of flow-error self-consistency for classical detectors (Otsu / watershed / hysteresis), which emit no dense per-pixel field to disagree with? Three candidates, none of them in the existing catalogue, all cheap:

  • threshold-stability under perturbation;
  • agreement across the existing detector ensemble;
  • re-deriving a boundary field from the mask and comparing it against the enhance/_focus_edge_* gradient response the pipeline already computes.
