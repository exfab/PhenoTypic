Follow-up to the hyphae-detection method tree · cross-field research

Everything thin detects as fragments — and every field reinvented how to reconnect it

Start with the question that prompted this: in the cosmic web, filament detection is notoriously broken. Skeletons come out as short, disconnected arcs salted with spurious segments, because the network is traced from a sparse, noisy point cloud and topological ridge-finders faithfully skeletonize the noise too. So cosmology built machinery to decide real vs. spurious and stitch the survivors into one network — persistence thresholds, multiscale classifiers, stochastic and graph-regularized assembly.

The striking part: the same problem, and strikingly similar fixes, recur in seven other fields that the fungi-detection method tree borrowed from. Thin curvilinear structures — filaments, neurons, particle tracks, vessels, roads, roots, faults, cytoskeletal fibers — all detect as fragments under noise, crossings, and occlusion, and each discipline independently converged on a small set of reconnection strategies. This report compiles what each field found, with citations, and maps every fix back to a method in the tree.

The seven reconstruction strategy families

Across all eight fields, every fix falls into one of these families. Most fields combine two or three. The recurring logic: detect fragments → decide which are real → bridge or assemble the survivors.

A · significance thresholding

Keep only what's real

Score every candidate segment and delete the noise-born ones below a cut, so what remains can connect cleanly.

persistence Nσ · Kalman hole-budget · length/intensity pruning · flow-accumulation threshold

B · least-cost / geodesic path

Carve a corridor through the gap

Build a cost/likelihood field and route a minimum-cost path between fragment ends; a broken-but-likely structure still forms a cheap corridor.

GWDT / Dijkstra · A* over a distance map · depression-filled D8 routing

C · predict-and-coast tracking

Extend through the gap along orientation

Follow a hypothesised trajectory; when evidence is missing, propagate the prediction (coast) across the dropout instead of terminating.

combinatorial Kalman · streamline integration · stretching active contours

D · global graph / optimization

Assemble fragments into the network

Solve for the entire connected structure jointly — pair fragments, classify edges, or regularize a spanning tree to build the whole structure — from global joint solutions (MST, GNN) to iterative cost-ranked terminus pairing.

regularized MST (T-ReX) · GNN edge classification · SIFNE fragment-pairing · global tractography

E · swarm / voting reinforcement

Let distributed evidence accumulate

Many agents or votes reinforce coherent structure while incoherent noise fails to accumulate — connectivity emerges statistically.

seismic ant-tracking · tensor voting · Rolling Hough coherence · Bisous point process

F · topology-aware learning

Penalize breakage during training

Replace pixel-overlap losses (which are topology-blind) with losses that reward an unbroken 1-D skeleton or matching Betti numbers.

clDice · persistent-homology / Betti loss · homotopy warping

G · multiscale evidence recovery

Recover the crest at the scale it survives

A structure broken at one scale is coherent at another; decompose across scales, clean each, and recombine.

NEXUS+ Hessian signature · getfilaments · curvelet denoising (CT-FIRE)

Cosmology — the cosmic web

DisPerSE · NEXUS+ · Bisous · T-ReX · families A·D·E·G
fragmentation: intrinsic
Why it fragments

Filaments are traced from a discrete, sparse point cloud (galaxies/particles). The density field must be estimated first, and every estimator injects shot noise; a Morse skeleton then faithfully traces each noise bump as its own short arc. Disagreement between methods is worst exactly where filaments are faint (signal ≈ noise).

How it reconnects

Persistence Nσ thresholding (DisPerSE): pair each critical point with its topological partner and cancel low-persistence pairs — the principled real-vs-spurious cut (higher σ = cleaner but sparser). Plus pre-smoothing to tame shot noise, multiscale Hessian classification (NEXUS+), a stochastic marked point process that builds connectivity into its prior (Bisous), and bootstrap-averaged regularized minimum spanning trees (T-ReX) that replace one jagged MST with a smooth traversal-frequency network.

Maps to method tree DisPerSEFilFinderPH/Morse (GUDHI)
Inputs

DisPerSE / NEXUS+ ← an estimated density field (DTFE / Delaunay) over the galaxy-or-particle point cloud; Bisous / T-ReX ← the raw point set; FilFinder / GUDHI ← a 2D intensity map / scalar field.

Astronomy — ISM & molecular-cloud filaments

FilFinder · Rolling Hough · getfilaments · families A·B·E·G
fragmentation: common
Why it fragments

A physically continuous filament is thresholded on a noisy field with a bright, varying background, so intensity dips along the crest sever the spine and noise spawns spurs. Green+ 2017 show extraction is acutely parameter-sensitive — varying DisPerSE/FilFinder inputs yields thousands of visibly different skeletons (historically chosen by eye; they propose MSSIM as an objective goodness-of-fit).

How it reconnects

FilFinder: arctan-flatten → adaptive (local-median) threshold so faint crests survive → medial-axis skeleton → prune a spur only if deletion preserves connectivity and it is short and faint → convert to a weighted graph and take the longest path as the spine. Rolling Hough Transform abandons contiguous spines: an unsharp-mask bit-mask + a rolling circular window records orientation only where signal fills a coherence fraction Z — recovering faint diffuse fibers near the noise. getfilaments cleans each spatial scale separately then recombines.

Maps to method tree FilFinderRolling Hough Transform
Inputs

Mostly a 2D dust or HI intensity map — FilFinder adaptive-masks it, RHT unsharp-masks it to a bitmask, DisPerSE uses the scalar field directly; getsf multi-scale-decomposes a multi-wavelength image set; RadFil ← FilFinder's mask + spine.

Neuroscience — neuron tracing & dMRI tractography

APP2/GWDT · ACT · global tractography · families A·B·C·D
fragmentation: dominant error
Why it fragments

In microscopy tracing, dim distal neurites, low SNR, and dense overlapping neuropil make tracers drop or split branches — the BigNeuron benchmark found no single algorithm reconstructs all neurites. In tractography the analog is premature streamline termination at crossing/kissing fibers, since one voxel's orientation cannot resolve sub-voxel geometry.

How it reconnects

Tracing: a grey-weighted distance transform lets geodesic shortest-paths follow dim signal and bridge small gaps (APP2), after which the over-connected distance-tree is hierarchically pruned to keep true branches. Tractography: Anatomically-Constrained Tractography uses tissue priors so streamlines only terminate at the grey/white boundary (suppressing spurious mid-tract breaks), and global tractography fits the whole fiber configuration at once. The universal tension: fewer broken tracts ⇄ more false continuations.

Maps to method tree GWDT / APP2dMRI tractography
Inputs

APP2 / GWDT / Rivulet ← a 3D grayscale image stack (+ an optional soma/root marker, else auto-detected); DIPY / MRtrix tractography ← a dMRI orientation / ODF field + seeds (ACT adds a tissue 5TT map); FINTA ← an existing streamline set (tractogram).

High-energy physics — track finding

combinatorial Kalman · cellular automaton · GNN · families A·C·D
fragmentation: designed-for
Why it fragments

A particle doesn't leave a hit on every layer it crosses — sensor inefficiency, dead modules, acceptance gaps, and high-occupancy pileup all mask hits. A track that loses hits fragments into shorter candidates or is lost. Reconstruction treats missing hits as the norm, not an anomaly.

How it reconnects

The combinatorial Kalman filter predicts the next layer, opens a search road, and updates with any compatible hit — crucially it coasts when the gate is empty, recording a "hole" and continuing rather than terminating; a bounded hole budget rejects fragments. The cellular-automaton finder chains collinear segments, skipping to next-but-one layers to bridge a missing hit, keeping the longest chain at forks. GNN pipelines (Exa.TrkX) classify candidate edges — including gap-skipping edges — to connect hits into tracks. The dial everywhere: ghosts ⇄ efficiency.

Maps to method tree Kalman track findingCellular-automaton track finder
Inputs

All take the per-event set of detector hits (3D space points across tracker layers); the combinatorial Kalman also needs a seed, and Hough builds a (φ₀, q/pT) track-parameter accumulator from those hits.

ImplementationsKalman finder ACTS·C++GNN GNN4ITk·GPUKF primitive filterpy·staleCA finder TrickTrack·archivedHough seeding framework-only→port

Key sources: Bertacchi+ 2021 (Belle II CKF); Kisel 2016 & Rohr+ 2017 (CA); Ju+ 2021 (Exa.TrkX GNN); Kiehn+ 2019 (TrackML). See references.

Vascular imaging & aerial road networks

clDice · Betti loss · tensor voting · RoadTracer · families D·E·F
fragmentation: the core failure
Why it fragments

It is fundamentally a topology problem, not accuracy. Vessels/roads are thin, so standard per-pixel losses (CE, Dice) are overlap measures: missing the few pixels along a connector barely moves the loss, yet severs the structure. For roads, trees, shadows, and overpasses occlude the evidence exactly where continuity matters.

How it reconnects

Topology-aware losses: clDice computes Dice on the soft centerline (rewards unbroken 1-D topology); TopoLoss matches Betti numbers via persistent homology; homotopy warping weights topologically critical pixels. Iterative tensor voting propagates orientation/saliency to bridge gaps classically. And instead of segment-then-skeletonize, graph tracers (RoadTracer, Sat2Graph) build the network directly, avoiding disconnections that pixel masks bake in; orientation-learning auxiliaries (Batra+ 2019) sharply cut broken segments.

Maps to method tree clDicePersistent-homology / Betti lossTensor votingOrientation-aware tracing nets
Inputs

The topology losses take a (predicted probability map, GT mask) pair at training — clDice/Betti on the soft prediction, homotopy warping on the prediction thresholded to a binary mask; tensor voting ← curve tokens (points + orientations) from a segmented, skeletonized network; B-COSFIRE / RoadTracer / Sat2Graph ← the raw image (RoadTracer also a start vertex).

Plant roots — root system architecture

RootNav · RootNav 2.0 · families B·D
fragmentation: defining challenge
Why it fragments

Roots are thin and low-contrast and repeatedly cross, touch, and occlude one another; in soil/agar/rhizotrons the background adds clutter. A single root reads as several disconnected components wherever it dips below contrast or passes under another root, and a crossing looks identical to a true branch point.

How it reconnects

RootNav: expectation-maximization estimates a per-pixel root-likelihood surface, then A* least-cost search finds paths seed→apex — a broken-but-likely root still forms a low-cost corridor. RootNav 2.0: a CNN emits a 3-class segmentation plus seed/tip heatmaps, converts segmentation to a distance map (root centers cheap, non-root heavily penalized), and runs A* least-cost search to trace the connected hierarchy (first-order, then second-order), with separate graphs per order to reduce crossing confusion. Graph + architecture models explicitly distinguish overlaps from branches.

Maps to method tree Dijkstra least-cost reconnection (branch_pathfinding)
Inputs

RootNav v1 ← an EM root-likelihood surface from the RGB image + seed points; RootNav 2.0 ← the RGB image → CNN segmentation + seed/tip heatmaps → distance map; RhizoVision ← a binary root mask; RSA ← a segmented/binary root image (skeletonized to a graph internally).

ImplementationsRootNav 2.0 RootNav-2.0·BSDRootNav v1 GUI·2017RhizoVision GPL appRSA (Leitner) MATLAB→port

Key sources: Pound+ 2013 (RootNav); Yasrab/Pound+ 2019 (RootNav 2.0, A*); Leitner+ 2014 (graph overlap model). See references.

Geophysics & hydrology — faults & drainage

seismic ant-tracking · D8 flow accumulation · families A·B·E
fragmentation: common (both)
Why it fragments

Seismic faults are inferred from discontinuity attributes (coherence/variance) that respond to any reflector break — noise, footprint, channels — so a true fault appears as a broken cloud of high-discontinuity voxels. DEM drainage: raw elevation models contain spurious pits and flats, so steepest-descent routing dead-ends and the extracted stream network is discontinuous.

How it reconnects

Ant-tracking (seismic): thousands of swarm agents walk the attribute along locally consistent fault orientations, depositing pheromone that reinforces genuine planar trends while isolated noise is not reinforced — connecting fault fragments into continuous surfaces. Hydrology: remove pits by filling or breaching (Lindsay's least-cost hybrid), then D8 routes each cell to its steepest neighbour, guaranteeing a connected, rooted drainage network (a forest of trees, one per outlet); thresholding flow accumulation yields the stream network.

Maps to method tree Ant-colony oriented votingD8 flow accumulation
Inputs

Ant-tracking ← a seismic discontinuity-attribute volume (coherence / variance); FaultSeg3D ← the raw 3D amplitude volume; D8 / breach-fill ← a DEM (elevation raster).

ImplementationsD8 accumulation whitebox / pyshedsbreach/fill whiteboxFaultSeg3D CC BY-NCant-tracking Petrel commercial→port

Cytoskeleton & biopolymer fiber networks

SOAX · SIFNE · CT-FIRE · families C·D·G
fragmentation: intrinsic output
Why it fragments

Broken filaments are the expected tracer output for actin/microtubule/collagen imaging: at X/T crossings a tracer can't decide which branch continues and terminates; low/inhomogeneous SNR, photobleaching, and uneven labeling leave sub-threshold gaps. Reconnection is a defining step of every major tool.

How it reconnects

SOAX: stretching open active contours grow along ridges, a stretch force lets a tip bridge gaps to reach bright filament ahead; on collision they form T-junctions that are clustered and spliced for correct topology. SIFNE: oriented-filter detection → fragments (crossing points removed) → for each fragment terminus, search a fan for partner termini and score by directional similarity + continuity (proximity-gated), iteratively linking them by a local, cost-ranked pairing rule into composite filaments. CT-FIRE: curvelet denoise + distance-transform ridge tracing with nodal linking (explicit gap-fill remains its stated limitation).

Maps to method tree SOAXSIFNECT-FIRE
Inputs

All take a 2D/3D fluorescence or SHG image — SOAX ridge-seeds it, SIFNE oriented-filters it into fragments, CT-FIRE curvelet-denoises then distance-transforms it (FIRE skips the curvelet step).

The pattern the artifact was built around. The fungi method tree's Phase-2 "reconnection" stage is not a niche microbiology trick — it is the same problem eight mature fields independently solved. The transferable lessons: (1) decide significance explicitly (a persistence / hole / length threshold) before you connect, or you will connect noise; (2) bridge over a cost field rather than requiring contiguous evidence; (3) for learned methods, make the loss see topology (clDice/Betti), because overlap losses reward broken structures; (4) when local linking is ambiguous, assemble globally (MST/pairing/GNN) instead of greedily.
