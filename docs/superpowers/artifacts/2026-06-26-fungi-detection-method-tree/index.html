Sorted top-to-bottom by recommended try-sequence: start with what's already in the repo as a diagnostic control, then cheap training-free classical experiments, then reconnection swaps for Dijkstra, and finally the learned path once labels/synthetic data exist. Start here — baseline & diagnostic control

Already in the repo, zero new dependencies. Run these first to bucket the baseline's failures (faint-miss vs. junction-break vs. colour-fringe) — the experiment that tells you which regime dominates and where to spend the next slot.

Phase congruency & contrast-invariantS2 · baseline

Mechanism: finds features where Fourier components are maximally in phase, giving a dimensionless 0–1 ridge measure that is contrast-invariant — faint hyphae register without per-image intensity tuning. The current detector's front end.

  • Phase congruency (Kovesi)BASEIN REPO
    Log-Gabor quadrature bank → local energy / Σ-amplitude, with a Rayleigh-noise threshold. The reference front end of the baseline detector.
    mathPC = E / (Σn An + ε); local energy E = √[(Σ Ancosφn)² + (Σ Ansinφn)²] over a log-Gabor bank (n scales × m orientations); PC2 adds a noise floor T and phase-deviation weighting W.
    how1 convolve with the log-Gabor quadrature bank → 2 per orientation compute local energy and mean phase, subtract the estimated Rayleigh noise floor T → 3 sum the weighted, phase-deviation-penalized congruency over orientations and normalize by total amplitude → 4 threshold / non-max-suppress the 0–1 map.
    used in Image-quality metrics (FSIM/feature similarity), illumination-invariant edge & corner detection in CV research; PhenoTypic's hyphae front end.
    enhance/_focus_edge_phase.py (own phasecong3) · ext: phasepack (inactive 2016)
  • Monogenic / Riesz PCCAVEAT
    Innovates: swaps the oriented log-Gabor sweep for an isotropic bandpass × the Riesz transform → amplitude/phase/orientation for free, lower compute & memory, better localization.
    mathmonogenic signal (f, Rxf, Ryf) via Riesz kernel (u,v)/|(u,v)|; amplitude A = √(f²+Rx²+Ry²), phase φ, orientation θ analytic per scale; PC = E/(ΣA+ε).
    how1 bandpass-filter at several scales (no orientation sweep) → 2 apply the Riesz transform for the two odd channels → 3 read per-scale amplitude / phase / orientation analytically → 4 accumulate congruency across scales and normalize.
    used in Medical image registration & ultrasound local-phase analysis; rotation-covariant feature extraction.
    phasepack.phasecongmono · unmaintained
  • Colour / multichannel PC (CMPCM)PORT IT
    Innovates: computes phase congruency jointly across RGB in a conformal-monogenic frame → colour-native edge detection with better noise suppression. (CA relevance is our extrapolation — the source paper claims edge localization, not chromatic-aberration removal.)
    mathlift RGB into a conformal (stereographic) monogenic / geometric-algebra signal; congruency computed jointly over channels; edges = maxima of the conformal-monogenic PC response.
    how1 map the colour signal into the conformal monogenic framework → 2 compute per-scale conformal-monogenic phase & amplitude jointly across channels → 3 locate PC maxima → 4 threshold; channel-consistent ridges survive, single-channel fringes do not.
    used in Colour edge-detection research (benchmarked on Pratt's Figure of Merit); not in production pipelines.
    no maintained impl — paper only
Hessian / 2nd-derivative ridge geometryS2

Mechanism: eigenvalues of the Gaussian-smoothed Hessian — a ridge gives one near-zero eigenvalue (along) and one large (across); the eigenvector is orientation. Junction weakness: at a crossing both eigenvalues grow large, so vesselness collapses to ~0.

  • Frangi vesselnessBASEIN REPO
    Blobness × structureness on Hessian eigenvalues, max over σ. The canonical tubularity filter — the control that confirms junction-suppression on your data.
    matheigenvalues |λ₁|≤|λ₂|; V = exp(−Rβ²/2β²)·(1−exp(−S²/2c²)), Rβ=|λ₁|/|λ₂|, S=√(λ₁²+λ₂²); V=0 if λ₂>0 (bright ridge); max over σ.
    how1 smooth at scale σ → 2 build the Hessian and eigendecompose → 3 map the blobness ratio Rβ and structureness S to a [0,1] score → 4 take the max across σ to span hyphal widths → threshold.
    used in Clinical vessel enhancement — retinal fundus, CT/MR angiography, lung & liver vasculature; shipped in ITK / scikit-image.
    enhance/_focus_edge_frangi.py · skimage.filters.frangi (BSD)
  • Sato tubularityIN REPO
    Innovates: asymmetric cross-eigenvalue weighting → handles low contrast better than Frangi (same junction weakness).
    mathline measure on sorted eigenvalues (λ₁≈0 along; λ_c<0 across) with separate factors α₁,α₂ for the λ_c<0 vs λ_c>0 regimes; scales integrated with per-σ noise equalization.
    how1 Gaussian-smooth → 2 Hessian + eigendecompose, identify the cross-section plane → 3 score "lineness" with asymmetric α-weighting (tolerant of contrast variation) → 4 integrate scales with noise equalization.
    used in 3D vessel, airway & bronchus enhancement in CT; medical visualization (ITK).
    enhance/_focus_edge_sato.py · skimage.filters.sato
  • Meijering neuritenessIN REPO
    Innovates: a modified eigenvalue tuned for low-SNR, intensity-inhomogeneous filaments.
    mathmodified eigenvalue λ′ = λ + α·λ⊥ (α=−⅓ in 2D); neuriteness = λ′/λ′min normalized over the image; max over σ.
    how1 Hessian at σ → 2 form the modified eigenvalue via the α-combination → 3 normalize by the most-negative modified eigenvalue in the image → 4 max over σ.
    used in Neurite / filament tracing in fluorescence microscopy (ImageJ/Fiji, scikit-image).
    enhance/_focus_edge_meijering.py · skimage.filters.meijering
  • Jerman enhancementCAVEAT
    Innovates: an eigenvalue ratio (not products) → reinforces bifurcations, single τ knob.
    mathV = λ₂²·(λ_ρ−λ₂)·[3/(λ₂+λ_ρ)]³, with λ_ρ = λ₂ clamped to a fraction τ·max|λ₂|; normalized to [0,1], max over σ.
    how1 multiscale Hessian eigenvalues → 2 regularize the 2nd eigenvalue against τ·max|λ₂| (lifts response at edges/junctions) → 3 compute the ratio-based vesselness → 4 max over scales.
    used in Vascular enhancement for aneurysm / bifurcation angiography (research).
    ~30-line skimage-Hessian DIY · ref MATLAB timjerman/JermanEnhancementFilter
  • Steger unbiased line detectorPIP · OSS
    Innovates: sub-pixel centerline + marks junctions and splits lines into a connected graph rather than erasing crossings. Closest classical fit to the brief; same hysteresis idiom as the baseline.
    mathHessian eigenvector n = line normal; sub-pixel line point where the 2nd directional derivative along n is extremal (1st deriv along n = 0, Taylor test); link by upper/lower hysteresis; split at claimed points = junctions.
    how1 convolve with Gaussian-derivative kernels (σ ≳ line-width/√3) → 2 form H, take the max-|λ| eigenvector as the normal, solve the Taylor test for the sub-pixel ridge point → 3 link points by hysteresis double-threshold on the 2nd directional derivative → 4 where a point is already claimed, mark a junction and split → connected lines-and-junctions graph.
    used in Industrial machine vision — sub-pixel road-marking, laser-line / weld-seam, fibre & DNA measurement (ships in MVTec Halcon).
    pip install ridge-detector (active 2024)
  • Optimally Oriented Flux (+antisymmetry)CAVEAT
    Innovates: flux through a local sphere boundary (not a solid Hessian) → resolves adjacent hyphae, recovers weak low-SNR ridges, no large-σ smoothing.
    mathoriented-flux matrix Qr(x) = image 2nd-derivatives convolved with a sphere-surface kernel of radius r; eigenvalues λ₁≤λ₂ of flux; pick r* maximizing response. Antisym = odd flux term flags edge/fringe steps.
    how1 for each candidate radius r build the oriented-flux matrix Qr(x) (gradient flux through a sphere of radius r) → 2 eigendecompose Qr → 3 combine eigenvalues into a vesselness-like response and pick the radius maximizing it → 4 down-weight locations flagged by the antisymmetric (edge) response, threshold.
    used in Multiscale vessel & airway segmentation research (neuro / vascular CT).
    fepegar/optimally-oriented-flux (3D-leaning, stale, no PyPI)
  • Bowler-hat transformCAVEAT
    Innovates: oriented line structuring elements instead of eigenvalues — a long line SE still fits across a junction, so crossings are enhanced as brightly as the limbs joining them.
    mathB = maxscale d [ maxθ open(I, lined,θ) − open(I, diskd) ] — pixels where an aligned line SE survives but a disk SE does not.
    how1 open with growing disks (kills thin structure) → 2 open with matching oriented line SEs at many θ (preserves aligned thin structure) → 3 take the per-scale line−disk difference → 4 combine across scales/orientations into the enhancement map, threshold.
    used in Retinal & micro-vascular enhancement research; plant-root and vessel networks.
    CigdemSazak/bowler-hat-2d (stale) — numpy DIY feasible

Cheap classical experiments — training-free, mostly pip

Low-commitment, reversible. These stack with the existing front end (S1 enhancers) or A/B against phase congruency (S2 detectors). Lead with whichever regime the Phase-0 buckets surfaced.

Oriented templates / matched / steerableS1·S2

Mechanism: correlate an oriented template (or synthesise oriented response from a basis) and take the max over orientation. Integrates evidence along the line → the canonical low-SNR booster.

  • Matched filters (Chaudhuri)BASECAVEAT
    Rotated Gaussian-cross-section template bank, max response. The original along-line low-SNR detector; fixed profile blurs junctions.
    mathzero-mean (DC-removed) Gaussian-profile template; bank of K rotations (classically 12 @ 15°); response = maxθ (I ∗ kernelθ), then threshold (MF-FDOG / hysteresis).
    how1 design one Gaussian-profile, zero-mean (DC-removed) template the width of a hypha → 2 rotate it into a 12-orientation bank → 3 correlate each with the image → 4 take the per-pixel max over orientations and threshold (often paired with a first-derivative MF-FDOG gate).
    used in Retinal vessel segmentation (classic DRIVE pipelines); known-profile template detection.
    no pkg — trivial rotated-Gaussian kernel bank (numpy/scipy)
  • Template / normalized cross-correlationPIP · OSS
    Innovates: generalises the matched filter to any elongated template via normalized cross-correlation; no extra deps.
    mathNCC = Σ(f−f̄)(t−t̄) / √[Σ(f−f̄)²·Σ(t−t̄)²] ∈ [−1,1]; slide template, max over rotations.
    how1 pick an elongated reference template → 2 slide it over the image computing normalized cross-correlation at each location (contrast/brightness-invariant) → 3 repeat over template rotations and take the max → 4 threshold the correlation peaks.
    used in Ubiquitous — defect inspection, object localization, particle picking, stereo matching (OpenCV / skimage everywhere).
    skimage.feature.match_template (BSD)
  • Steerable filters (Freeman–Adelson)CAVEAT
    Innovates: response at any angle in closed form from a small basis → continuous per-pixel orientation without re-filtering.
    math1st order: Gθ = cosθ·Gx + sinθ·Gy (higher orders add G2 ridge + Hilbert pair H2); θ-response interpolated analytically; arg-max θ = orientation, quadrature energy = ridge strength.
    how1 convolve once per basis filter (a small fixed set) → 2 interpolate the response at any angle θ in closed form → 3 solve analytically for the orientation maximizing response → 4 take that oriented quadrature energy as ridge strength, threshold.
    used in Orientation & texture analysis, adaptive anisotropic filtering, image pyramids (computational-vision research).
    pyrtools (MIT, pyramid) / cvsteer (direct G2/H2, stale)
  • Gabor / log-Gabor banksPIP · OSS
    Innovates: oriented sinusoid × Gaussian envelope; log-Gabor removes DC and covers high frequencies → tunable oriented bandpass.
    mathg = exp(−(x′²+γ²y′²)/2σ²)·cos(2πx′/λ+ψ), (x′,y′) rotated by θ; feature = magnitude/energy pooled over a θ×scale bank.
    how1 build a kernel bank over orientations × scales → 2 convolve the image with each → 3 take magnitude and reduce per pixel (max or energy across the bank) → 4 threshold the energy map (orientation = arg-max kernel).
    used in Production biometrics — fingerprint & iris enhancement (AFIS), texture classification, OCR.
    skimage.filters.gabor (BSD) — note: log-Gabor pkg is GPL
  • B-COSFIRECAVEAT
    Innovates: AND-like collinear pooling fires only on co-occurring evidence (grain suppression); configured from one prototype, bifurcation variant.
    mathconfigure DoG subunits at (ρi,φi) along a prototype; response = weighted geometric mean r = (Πi siwi)1/Σw of blurred shifted DoG; max over rotations.
    how1 present one prototype line to auto-configure DoG subunit positions (ρi,φi) → 2 blur and shift each DoG response toward the support centre → 3 combine by weighted geometric mean (strong only where collinear evidence co-occurs) → 4 max over rotations, threshold (symmetric "bar" variant for bifurcations).
    used in Retinal vessel delineation (DRIVE / STARE benchmarks, research).
    Brains-for-hire/bcosfire_python (stale; MATLAB orig non-commercial)
Morphology / path-operators / multiscale transformsS1·S2

Mechanism: select structures by the length of an admissible path through them (not local curvature), or by sparse anisotropic frames. Avoids the local-neighbourhood analysis that breaks Hessian filters at junctions.

  • Grayscale top-hat (oriented line SE)BASEIN REPO
    Opening residual → cheap background subtraction + thin-bright enhancement. Already used in the repo.
    mathwhite top-hat WTH(f) = f − (f ∘ B) (∘ = opening); for oriented thin structure, max over rotated linear SEs: maxθ WTH(f, lineθ).
    how1 open the image with a structuring element B sized just larger than a hypha (removes thin bright features) → 2 subtract the opening from the original (the residual isolates structures thinner than B) → 3 optionally repeat over rotated linear SEs and take the per-pixel max → 4 threshold / hysteresis.
    used in Ubiquitous preprocessing — uneven-illumination correction + small-bright-feature extraction (microscopy spot/colony detection, OCR, defect inspection).
    enhance/_subtract_opening.py, _white_tophat_enhance.py · skimage
  • Path openings / closingsCAVEAT
    Innovates: a flexible near-straight path SE → keeps tortuous ridges; incomplete-path variant bridges gaps inline at linear cost.
    mathPOL(f)(x) = max over admissible paths π∋x with |π|≥L of (miny∈π f(y)) on an oriented adjacency graph; single length knob L.
    how1 build the oriented adjacency DAG (per direction) → 2 per orientation compute, in linear time, the longest admissible path length through each pixel → 3 keep pixels whose path length ≥ L (the single knob) → 4 max over orientations (incomplete-path variant tolerates short gaps along the path).
    used in Crack, road & fibre filtering; thin-structure extraction in remote sensing (morphology toolkits).
    bundled in path-openings/RORPO (C++/CMake build)
  • RORPOCAVEAT
    Innovates: a rank-gap across orientations → line-likeness without local Hessian collapse; reported up to +8% TP / −50% FP vs Frangi/OOF.
    mathpath-open along ~4 (2D)/7 (3D) orientations, sort responses POθ1≥…≥POθN; indicator RORPO = POθ1 − POθk (line → bright in few orientations → large gap).
    how1 path-open the image along each discrete orientation → 2 at each pixel sort the per-orientation responses → 3 difference the highest vs a lower rank (true line = bright in few orientations → large gap; blob = bright in many → ~0) → 4 threshold / hysteresis the line-likeness map.
    used in 3D vascular filtering research (liver / brain vessels); curvilinear remote sensing.
    path-openings/RORPO (pybind11, CeCILL) — compile required
  • Curvelet transformPIP · OSS
    Innovates: anisotropic tight frame → sparse oriented multiscale denoise + ridge enhancement (twin of CT-FIRE front end).
    mathcoefficients c(j,ℓ,k) = ⟨f, φj,ℓ,k⟩, needle atoms with parabolic scaling (width ≈ length²); shrink/threshold by per-angle coherence, reconstruct.
    how1 apply the fast discrete curvelet transform (FDCT) → 2 keep fine-scale coefficients with locally coherent orientation, shrink/threshold the rest → 3 reconstruct the denoised/enhanced image (or read dominant orientation + magnitude as a ridge map) → 4 threshold.
    used in Seismic denoising (geophysics production), MRI/CT denoising, collagen-fibre analysis (CT-FIRE).
    curvelets (UDCT, pure-Python, MIT, active) — CurveLab variant non-commercial
  • Shearlet transformCAVEAT
    Innovates: a shear (not rotation) gives lattice-exact directionality, GPU-able.
    mathψa,s,t(x) = a−3/4ψ(Aa−1Ss−1(x−t)), shear Ss=[[1,s],[0,1]], parabolic scaling Aa; orientation = maximizing shear; ridge = coefficient persistence across scale.
    how1 apply the discrete shearlet transform → 2 at fine scales locate persistent large coefficients (edge/ridge points), reading the maximizing shear as orientation → 3 build an oriented-response enhancement or denoise by thresholding coefficients → 4 threshold / hysteresis.
    used in Image denoising / inpainting, edge analysis, CT reconstruction (research).
    pyshearlab / pytorch_shearlets — GPL
Voting / transform accumulatorsS2

Mechanism: accumulate evidence in a parameter space (orientation, ρ–θ) so a faint coherent line beats the per-pixel noise floor — plus statistical false-alarm control.

  • Radon / Hough lineBASEPIP · OSS
    Line integrals / accumulator voting → peaks are lines. The canonical integration operator (too coarse alone for curved hyphae).
    mathR(ρ,θ) = ∬ f·δ(ρ − x cosθ − y sinθ) dx dy (Radon); discrete dual = Hough accumulator voting each edge pixel into its sinusoid ρ = x cosθ + y sinθ; peaks → lines.
    how1 build an edge/feature map → 2 each feature votes its sinusoid into the (ρ,θ) accumulator (or integrate intensity along every line) → 3 find accumulator maxima → 4 back-project the peaks to line segments.
    used in CT reconstruction (Radon is the core operator), lane/line detection (ADAS), barcode & document deskew.
    skimage.transform.radon / hough_line (BSD)
  • Rolling Hough Transform (RHT)PIP · OSS
    Innovates: windowed Hough on a bitmask → per-pixel orientation of faint diffuse lines below the noise floor, single knob Z.
    mathunsharp-mask → binary bitmask; within a circular window DW run a Hough restricted to ρ=0; record θ iff ≥ Z·DW on-bits lie along θ.
    how1 unsharp-mask (subtract a disk-smoothed copy) and threshold to a binary bitmask → 2 roll a circular window of diameter DW over the image → 3 in each window accumulate a 1-D Hough of orientation at ρ=0 → 4 threshold by the fraction Z to emit a per-pixel orientation field (optionally back-project to a mask).
    used in Radio astronomy — interstellar HI / ISM filament & magnetic-field-orientation mapping (FilFinder / astro pipelines).
    pip install fil-finder (MIT, active) — feed it a ridge map
  • Line Segment Detector (LSD)PIP · OSS
    Innovates: region-grow + statistical validation → parameter-free segments. Splits at junctions (curved hyphae fragment).
    mathlevel-line angle field → region-grow same-orientation "line-support regions" → fit rectangle → accept iff NFA = (NM)5/2·γ·B(n,k,p) ≤ ε (B = binomial tail of aligned pixels).
    how1 compute the level-line (gradient-tangent) angle per pixel → 2 region-grow connected pixels whose orientations agree within tolerance into line-support regions → 3 fit a rectangle and count aligned points → 4 keep only segments with NFA ≤ ε (a-contrario validation).
    used in SLAM / visual odometry real-time line detection, document & architectural analysis, calibration (OpenCV ecosystem).
    pylsd-nova · cv2.ximgproc FastLineDetector (Canny-based, not true NFA-LSD; LSD was removed from OpenCV ≥4.1)
  • A-contrario / NFA validationCAVEAT
    Innovates: Helmholtz null model → a threshold-free FDR layer over agar grain & fringe; one knob ε.
    mathNFA = Ntests·PH0(≥k of n aligned) ≤ ε; under noise the expected number of ε-meaningful detections ≤ ε (Helmholtz principle).
    how1 define a null/noise model H0 (e.g. uniform-random gradient orientations) → 2 enumerate candidate structures and their test multiplicity Ntests → 3 compute the tail probability of the observed alignment under H0 → 4 accept only candidates with NFA ≤ ε (it is a validation layer wrapped around a detector).
    used in Detection validation in CV research — alignments, vanishing points, change detection (statistical, threshold-free).
    only bundled inside LSD (no standalone Python)
  • Tensor votingPORT IT
    Innovates: votes through a decaying field → bridges gaps AND flags junctions (ball tensor) that Hessian filters suppress.
    mathtoken tensor T = (λ₁−λ₂)·ê₁ê₁ᵀ + λ₂·(ê₁ê₁ᵀ+ê₂ê₂ᵀ); orientation-weighted votes cast through a curvature-penalizing decaying field, tensor-summed; λ₁−λ₂≫0 = curve, λ₁≈λ₂ = junction.
    how1 encode each token (ridge point) as a 2nd-order symmetric tensor → 2 each token casts stick/ball votes to neighbours through a distance- and curvature-decaying field → 3 tensor-sum the votes at every site → 4 re-decompose: large stick saliency = on-a-curve (gaps filled), large ball saliency = junction.
    used in Perceptual grouping / gap-filling research; point-cloud surface inference, curve completion.
    no maintained Python — port from MATLAB/Java
Diffusion / structure-tensor enhancementS1

Mechanism: an anisotropic PDE steered by the local orientation field smooths along the structure to close interrupted lines; the structure tensor itself supplies the orientation/coherence field every oriented method downstream consumes. (Chromatic-aberration rejection is now its own class below.)

  • Coherence-enhancing diffusion (Weickert)BASEIN REPO
    Diffuses along the dominant orientation → closes interrupted line-like structures, single coherence knob. Already implemented.
    math∂tu = div(D∇u), D shares structure-tensor Jρ eigenvectors; λ₁=α (small, across), λ₂=α+(1−α)·exp(−C/κ²) (large, along), coherence κ=(μ₁−μ₂)².
    how1 compute the structure tensor Jρ and eigendecompose → 2 set the diffusion tensor D to diffuse strongly along v₂ (the coherence direction), weakly across → 3 evolve the PDE a few iterations → 4 read out the smoothed, gap-closed image (an enhancer, not a binarizer).
    used in Fingerprint / coherent-texture restoration, fibre & flow-line imaging (research, some forensic).
    enhance/_structure_smoothing.py
  • Structure-tensor orientation + coherenceIN REPO
    Innovates (as primitive): orientation field + coherence that flags junctions (coherence → 0). Feeds diffusion and reconnection.
    mathJ = Gρ ∗ (∇I∇Iᵀ); θ = ½·atan2(2Jxy, Jxx−Jyy), coherence c = ((μ₁−μ₂)/(μ₁+μ₂))² ∈ [0,1]; eigenvector v₂ = line direction.
    how1 compute smoothed gradient outer-products ∇I∇Iᵀ → 2 Gaussian-average over a scale ρ → 3 eigendecompose the 2×2 tensor per pixel → 4 emit an orientation field + coherence map (coherence → 0 flags junctions/isotropic regions).
    used in Ubiquitous primitive — fibre/material orientation mapping (OrientationJ), optic flow, corner detection.
    used in _structure_smoothing.py · ext structure-tensor (MIT)
  • Vesselness / PCT-enhancing diffusionCAVEAT
    Innovates: gates the diffusion by a vesselness/phase-congruency tensor → tubular-aware closing (inherits Hessian junction ambiguity). PCT validated on fungal networks.
    mathvesselness V (Frangi λ₁,λ₂ — or a Phase Congruency Tensor from log-Gabor phase energy) sets the diffusivity and direction of the anisotropic-diffusion tensor; iterate to lengthen ridges.
    how1 compute multi-orientation phase congruency → 2 build the Phase Congruency Tensor and eigen-analyze for orientation + (contrast-independent) vesselness → 3 diffuse along the vessel direction scaled by vesselness → 4 iterate to lengthen/close ridges before thresholding.
    used in Fungal / mycelial network analysis (the original Obara application) and vessel-enhancement research.
    combine repo vesselness + CED (no packaged coupled scheme)
  • Fingerprint ridge-flowCAVEAT
    Innovates: orientation-field-steered Gabor enhancement → ridge sharpening (binary-ridge bias; low coherence at crossings).
    mathstructure-tensor orientation field θ(x) → steer a per-pixel oriented Gabor (frequency = ridge spacing) aligned to θ → contrast-enhanced ridge map.
    how1 estimate the per-pixel orientation field from the structure tensor → 2 estimate the local ridge frequency/spacing → 3 apply a per-pixel Gabor filter tuned to (orientation, frequency) → 4 binarize the enhanced, regularized ridge map.
    used in Production fingerprint / AFIS enhancement (forensics, biometric authentication).
    fingerprint-enhancer (BSD-2, low activity)
Chromatic-aberration rejectionS0 · upstream

Mechanism: chromatic aberration paints coloured fringes along high-contrast edges that structurally mimic thin coloured filaments — the one confounder no single-channel ridge operator handles. Correct or reject it upstream (S0), before any oriented analysis runs; a parallel workstream triggered when the Phase-0 buckets show colour-fringe false positives.

  • Chromatic-aberration correctionBASECAVEAT
    Registers the colour channels (R,B → G) to remove the lateral colour fringe that mimics thin coloured filaments. Runs before everything.
    mathper-channel radial warp to green: Δr = a·r + b·r³ + c·r⁵ (radial-polynomial from optical centre), or a dense R↔G/B↔G registration; resample R,B onto G via sub-pixel interpolation.
    how1 detect high-contrast edges / keypoints across channels → 2 fit a radial-polynomial (or dense) R→G and B→G displacement model from the optical centre → 3 warp/resample R and B onto G's grid by sub-pixel interpolation → 4 residual desaturation of remaining fringe (runs before any ridge detection).
    used in Camera & lens pipelines — Lightroom / DxO / lensfun, microscopy, photogrammetry (production).
    lensfunpy (LGPL, needs lens profile) / OpenCV per-channel registration DIY
  • Cross-channel fringe suppressionPORT IT
    Innovates: kills purple/longitudinal CA where channels disagree, preserving achromatic hyphal ridges.
    mathflag fringe where colour gradient is large but cross-channel-inconsistent with luminance (∇C·∇G small) → desaturate toward G / shearlet-domain LUT re-align R,B to G; leave consistent edges.
    how1 compute per-channel gradients and chroma → 2 flag pixels where the colour gradient is strong but inconsistent with the luminance/green gradient (the CA signature) → 3 desaturate toward G or re-align R,B to G there → 4 leave cross-channel-consistent (genuine) edges untouched.
    used in Purple-fringe removal in consumer photo software (Lightroom defringe) and camera ISPs.
    no maintained pkg — small NumPy defringe DIY

Reconnection — feed or replace the Dijkstra step

Attacks the dense-overlap→gaps regime directly. These consume the baseline's fragment endpoints + orientation field and either bridge gaps locally (predict-and-track) or extract a connected skeleton globally (persistence).

Predict-and-track / graph linkingS3

Mechanism: follow a hypothesised path through dropouts using the local ridge orientation, gating each step, and link fragments into a graph. Training-free, seeds from baseline endpoints.

  • Dijkstra least-cost reconnectionBASEIN REPO
    Multisource least-cost path on a composite cost surface. The existing reconnection these alternatives are measured against.
    mathpath = argminπ Σx∈π c(x) on a composite cost c = f(phase energy, anisotropy, orientation coherence, local MAD) with gap/border penalties; multisource frontier.
    how1 build the composite cost surface from phase energy, anisotropy, orientation coherence and local MAD → 2 set sources at fragment endpoints → 3 run a multisource least-cost frontier (Dijkstra) → 4 trace the minimal-cost paths that bridge gaps and merge them into the objmap.
    used in Neuron / vessel tracing reconnection (Vaa3D, Simple Neurite Tracer), seam carving, route planning; PhenoTypic's current reconnector.
    sdk_/branch_pathfinding/
  • GWDT / APP2 neurite tracingPIP · OSS
    Innovates: a grey-weighted distance transform feeds the cost surface → closest drop-in upgrade for the existing Dijkstra.
    mathgrey-weighted distance transform GWDT (intensity-weighted geodesic distance) → shortest-path tree (Dijkstra/MST) from seeds; APP2 prunes the over-complete tree by coverage.
    how1 compute the grey-weighted distance transform (distance weighted by inverse intensity) from a root → 2 backtrace a shortest-path tree over all foreground voxels → 3 prune the over-complete tree by a coverage/redundancy criterion (APP2) → 4 emit the centerline graph.

Persistence / Morse skeleton topologyS3

Mechanism: extract a globally connected skeleton via topological persistence or steepest descent — a single persistence/significance knob instead of local pathfinding. Junctions appear as saddle points.

  • FilFinderBASEPIP · OSS

    mathadaptive local-threshold mask (after an arctan brightness-flattening step) → medial-axis skeletonization → skeleton graph, prune spurs by length/intensity → fit transverse (Gaussian/Plummer) radial profile for width.
    how1 build an adaptive-threshold mask of bright structure → 2 reduce it to a 1-pixel medial-axis skeleton → 3 convert to a graph and prune short/faint spur branches → 4 fit a transverse radial profile per spine for width and position angle.

    pip install fil-finder (MIT)
  • PH / Morse libraries (GUDHI)PIP · OSS
    Innovates: the persistence + cubical-complex engine for an in-Python DisPerSE-style pipeline (these libs give the persistence pairs; Morse-Smale skeleton extraction must be built on top).
    mathsublevel-set filtration of the intensity field → persistence diagram of (β₀ components, β₁ loops) with birth/death pairs; cancel low-persistence pairs (denoise). NB: GUDHI/ripser give persistence, not the Morse-Smale filament geometry — that is DisPerSE territory or extra code.
    how1 build a sublevel-set filtration / cubical complex from the intensity field → 2 compute persistence pairs (birth/death of components and loops) → 3 cancel low-persistence pairs (topological denoising) → 4 build the Morse-Smale 1-skeleton (saddle→maximum arcs) on top — the libs supply the persistence pairs, you supply the filament-extraction step.

    mathdensity as a discrete Morse function → Morse-Smale complex; filaments = ascending 1-manifolds (2-saddle → maximum); significance via persistence (death−birth) ≥ Nσ.
    how1 build the Morse-Smale complex from the discrete gradient of the (smoothed) density → 2 pair critical points and compute persistence → 3 cancel pairs below the Nσ threshold (topological denoising) → 4 keep the ascending 1-manifolds (saddle→maximum) as the filament skeleton.

    thierry-sousbie/DisPerSE (C++/CeCILL) — compile + file I/O
  • D8 flow accumulationCAVEAT

    how1 initialize φ from a seed/threshold → 2 compute the speed from region statistics (Chan–Vese) or edges (geodesic) → 3 iterate the level-set PDE with periodic reinitialization (topology splits/merges automatically) → 4 take {φ ≤ 0} (or a thin-tube variant) as the mask.

    how1 seed open snakes on intensity ridges (threshold τ) → 2 evolve each under internal smoothness + ridge force + an elongation/stretch force that grows it along the centerline → 3 detect snake collisions and construct/cluster/splice T-junctions → 4 output the centerline network, dilate to a mask.

CNN segmenters & imbalance lossesS2

Mechanism: an encoder–decoder learns the mask end-to-end; for an extreme-minority target the loss is the design decision, not the architecture.

  • U-Net / Attention U-NetBASEPIP · OSS
    Skip-connected encoder–decoder; attention gates up-weight sparse ridges. The reference biomedical segmenter.
    mathencoder conv→pool, decoder up-conv→concat(skip)→conv, 1×1 conv + sigmoid; loss = CE / soft-Dice. Attention gate: α = σ(ψᵀ·σ(Wxx + Wgg)), x̂ = α·x before concat.
    how1 contract: conv→pool down to coarse semantic features → 2 expand: up-conv and concatenate the same-resolution encoder skip (attention gate optionally re-weights it first) → 3 conv-decode to per-pixel probability → 4 threshold; train on small data with heavy augmentation.
    used in The default biomedical segmentation backbone — deployed across clinical & research imaging.
    segmentation-models-pytorch (MIT) / monai (Apache)
  • nnU-NetPIP · OSS
    Innovates: self-configures the whole pipeline from a dataset fingerprint → turnkey (heavy, medical-oriented).
    mathno new operator — rule-based + empirical mapping of a dataset fingerprint (spacing, shape, intensity histogram, class ratios) + GPU budget → patch/batch, depth/pooling, normalization; 5-fold CV ensemble + component postproc.
    how1 extract the dataset fingerprint → 2 derive preprocessing + network topology under the hardware budget → 3 train with deep supervision, heavy augmentation and 5-fold cross-validation → 4 auto-select the best config/ensemble and apply connected-component postprocessing.
    used in SOTA turnkey medical segmentation — challenge-winning, clinical-research pipelines.
    pip install nnunetv2 (Apache)
  • Tversky / Focal lossPIP · OSS
    Innovates: asymmetric weighting recovers faint false-negative branches → attacks thin-structure class imbalance.
    mathTversky TI = TP/(TP + α·FP + β·FN), loss (1−TI)γ (β>α favours recall); Focal FL = −αt(1−pt)γ·log pt down-weights easy background.
    how1 compute soft TP/FP/FN (or per-pixel pt) from the prediction → 2 apply asymmetric weighting (β ≫ α to punish missed foreground) and/or the focal exponent γ → 3 backprop, emphasizing faint false-negative branches and hard pixels → used alongside (not instead of) a topology loss.
    used in Standard imbalance-loss library for lesion segmentation & dense detection (smp / MONAI).
    smp.losses / monai
  • DeepCrackCAVEAT
    Innovates: multi-scale deep-supervised fusion for thin cracks — the closest analog to oriented ridges.
    mathSegNet encoder–decoder with side outputs at 5 scales, encoder/decoder features pairwise fused; L = Σs ws·BCE(sides, y) + BCE(fused, y) (deep supervision).
    how1 encode through the SegNet backbone → 2 at each of 5 scales fuse the paired encoder + decoder features into a side-output crack map → 3 deeply supervise every side output → 4 fuse all scales into the final map (fine maps catch tips, coarse maps the topology).

  • D-LinkNetCAVEAT

    mathResNet-34 encoder + a cascade + parallel of dilated convolutions (rates 1,2,4,8) in the centre block (enlarges receptive field without resolution loss) + LinkNet decoder; BCE+Dice.
    how1 encode with ResNet-34 → 2 pass features through a cascade of dilated convolutions in the bottleneck (large receptive field, full resolution) → 3 decode with LinkNet skip-adds → 4 sigmoid + threshold the long-line road/ridge map.
    used in Aerial / satellite road extraction (DeepGlobe winner; remote-sensing mapping).

    mathStage 1 detector → boxes b=(x,y,w,h); Stage 2 fine segmenter on the cropped (optionally upsampled) patch x[b], raising the FG/BG ratio; stitch back.

Topology-aware losses & tracing netsS2·S3

Mechanism: penalize topological errors (breaks/merges), not just per-pixel overlap — the learned analog of junction preservation. Drop-in riders on any segmenter.

  • clDice / soft-clDiceBASEPIP · OSS
    Overlap of soft skeletons → provably preserves topology up to homotopy, recovers gap false-negatives. Drop-in differentiable loss.
    mathsoft skeletons S=skel(V) via iterated min/max-pool; Tprec=|SP∩VL|/|SP|, Tsens=|SL∩VP|/|SL|; clDice = 2·Tprec·Tsens/(Tprec+Tsens); L=(1−α)LDice+α(1−clDice).
    how1 differentiably skeletonize both prediction and label (iterated soft min/max-pool morphology) → 2 measure each skeleton inside the opposite mask (topology precision & sensitivity) → 3 harmonic-mean them into the clDice connectivity score → 4 blend with soft-Dice via α and backprop.
    used in Connectivity-aware vessel / road / neuron segmentation (research; adopted in topology-aware pipelines).
    jocpae/clDice (MIT, git-install)
  • Skeleton Recall LossPIP · OSS
    Innovates: CPU skeleton target → >90% cheaper than clDice, multi-class scalable.
    mathGT skeleton SL (CPU thinning) dilated by a radius-2 diamond → tube T; soft recall LSR = 1 − (ΣT p·g)/(ΣT g) (topology compute moved off-GPU).
    how1 skeletonize the GT once on CPU (morphological thinning) → 2 dilate the skeleton to a thin tubular band → 3 compute the soft recall of the prediction inside that band → 4 add it to the base loss (no GPU soft-skeleton, hence cheap).
    used in Tubular / thin-structure segmentation training as an nnU-Net plugin (recent adoption).
    MIC-DKFZ/Skeleton-Recall (Apache, active)
  • Persistent-homology / Betti lossCAVEAT
    Innovates: matches persistence diagrams → spatially-localized β₀/β₁ penalty (most principled, higher cost).
    mathsublevel filtration → persistence diagram (β₀, β₁, birth/death); optimally match pred↔GT diagrams; Ltopo = Σ (persistence of unmatched critical features)², backprop through critical pixels.
    how1 build a filtration of the likelihood map and extract its persistence diagram (β₀ components, β₁ loops) → 2 compute the GT diagram and optimally match features → 3 penalize unmatched/short-lived (topologically wrong) features → 4 backprop through the responsible critical pixels.
    used in Topology-enforced segmentation research — membranes, vessels.
    HuXiaoling/TopoLoss / Betti-Matching · backend torch_topological
  • Homotopy WarpingCAVEAT
    Innovates: works on the binary mask (not noisy likelihood), O(n); beats clDice on DRIVE Betti error.
    mathwarp pred↔GT through topology-preserving simple-point flips, identify critical pixels C via distance transform; Lwarp = Σx∈C BCE(px, gx), O(n).
    how1 warp the predicted binary mask toward GT (and vice versa) through topology-preserving simple-point flips → 2 identify the topologically-critical pixels that had to flip (via distance transform, O(n)) → 3 apply a focused BCE penalty only on those pixels → 4 blend with the overlap loss.
    used in Connectivity-aware curvilinear segmentation research.
    HuXiaoling/Warping (research)
  • Orientation-aware tracing netsCAVEAT
    Innovates: emit a centerline graph instead of a pixel mask (repo analog: branch_pathfinding).
    mathnext-direction head θt+1 = fφ(patch(xt), θt) (softmax over angles / von Mises) + step ℓ; xt+1 = xt + ℓ(cosθ, sinθ); spawn new tracers at branch points.
    how1 seed tracers at endpoints / high-evidence pixels → 2 crop a local oriented patch and predict the next direction + stop probability → 3 step forward (integrating evidence along the line), spawning new tracers at branch points → 4 repeat until stop, yielding an explicit connected graph.
    used in Road-network graph extraction from aerial imagery; vessel / neuron centerline-graph research.
    mitroadmaps/roadtracer (iterative agent) · anilbatra2185/road_connectivity (MIT — per-pixel orientation, not iterative)
Foundation segmentersS2

Mechanism: a large pretrained promptable ViT; zero-shot fails on thin branching structure, so the route is small-data adaptation. PhenoTypic already wraps SAM2/SAM3.

  • SAM (Segment Anything)BASEPIP · OSS
    Promptable ViT decoder. Zero-shot fragments faint thin vessels — the training-free end is foreclosed.
    mathfrozen ViT image embedding F + prompt embeddings → two-way transformer cross-attends output/mask tokens → M = upsample(F) · MLP(token) + IoU head; loss = focal + Dice.
    how1 the heavy ViT encodes the image once → 2 encode a point/box/mask prompt → 3 the lightweight two-way decoder fuses prompt + image tokens into 3 candidate masks + IoU scores → 4 automatic mode tiles a point grid (but fragments faint thin ridges).
    used in General promptable segmentation — annotation tooling, interactive cutout, dataset labeling (widely deployed).
    facebookresearch/segment-anything (Apache)
  • SAM2 (decoder-only fine-tune)IN REPO
    Innovates: freeze the hiera encoder, train the decoder only → robust small-data transfer, Colab-scale, "matches leading tools". The verified learned path.
    mathsame focal+Dice objective, but encoder + prompt encoder frozen, only θdec updated — parameter delta = the decoder head; train on tens–hundreds of masks.
    how1 freeze the hiera encoder + prompt encoder → 2 feed a small labeled set with point/box prompts → 3 backprop focal+Dice through the decoder only (single-notebook, no cluster) → 4 infer with the same prompting interface, now domain-tuned (degrades on finest branches).

    how1 aggregate corpora with mask + text pairs → 2 fully fine-tune the encoder + decoder + text path → 3 the semantic-alignment objective turns text embeddings into spatial queries → 4 at inference a text prompt ("hyphae") yields the mask with no clicking (no thin-ridge prior).

Reading the tree as a plan. The stages compose across phases — a defensible end-state is oriented-Gaussian/CED enhancement (Ph 1, S1) → Steger ridge graph (Ph 0/1, S2) → Kalman or GWDT reconnection (Ph 2, S3), with chromatic-aberration correction (Ph 1, S0) upstream throughout, and the learned path (Ph 3) reserved for once a small labelled or synthetic set exists.
