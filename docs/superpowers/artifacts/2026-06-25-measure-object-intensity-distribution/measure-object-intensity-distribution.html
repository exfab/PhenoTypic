MeasureObjectIntensity­Distribution

how intensity is arranged from each object's center to its rim — two independent representations

Given a grayscale image and a set of segmented objects, the module describes the internal spatial intensity distribution of every object. It emits two independent descriptions side by side: a non-parametric radial ring histogram (FracAtD · MeanFrac · RadialCV) and an optional orthogonal Zernike moment decomposition. They share no computation — different centers, different normalizations, different passes.

Part I — the radial ring profile (the math)

Stage 1 · center + normalized radius

Where is "center", and how far out is each pixel?

The center is the pixel farthest from any edge (the distance-transform peak — guaranteed inside even crescent shapes). Labels are then propagated outward geodesically to give each pixel a d_center; the EDT gives d_edge. compute_center_distances · measurement.py:3479

scaled (default):  ρ = dcenterdcenter + dedge + 0.001  → 0 at center, ≈1 at rim
unscaled:  ρ = dcenter / max_radius  → fixed physical scale

Center modes: SELF (own center), CENTERS_OF_OTHER / EDGES_OF_OTHER (radius from another object set — e.g. nuclei inside cells).

Stage 2 · bin + intensity fractions

FracAtD & MeanFrac

Each pixel lands in ring b = ⌊ρ·N⌋ (clipped to N → the Overflow slot). Sparse accumulation gives per-(object, ring) sums. compute_per_bin_distributions · measurement.py:3701

FracAtD(b) = Σp∈b I(p)Σp∈obj I(p)  intensity mass in ring b
MeanFrac(b) = FracAtD(b)Nb / Nobj = ring-b meanobject mean

FracAtD = where the stain mass sits (sums to 1 across rings). MeanFrac = the center→rim brightness profile; =1 average, >1 brighter than the object as a whole.

Stage 3 · angular anisotropy

RadialCV — is the ring lopsided?

Within each ring, split pixels into 8 angular octants around the center, take each octant's mean intensity, then the CV across the 8. compute_radial_cv_for_bin · measurement.py:3867

octant = 4·[ |Δi| > |Δj| ] + 2·[ j > jc ] + [ i > ic ]  → 0..7
RadialCV(b) = std8 octants( meanoctant )mean8 octants( meanoctant )

High RadialCV = the ring is bright on one side, dim on the other (sectoring / lopsided signal). Empty octants are masked; objects with no octant get CV 0.

Conceptually

A radial histogram

The ring path is piecewise-constant in radius, integrated over angle — local, directly readable, and tunable in resolution via bin_count (like the scale knob in texture: fine vs coarse, not "more accurate"). It throws away angular structure except for RadialCV's crude 8-bin anisotropy.

Scaled rings give a size-invariant morphology fingerprint; unscaled keeps physical distance and can reach past the object into background (the Overflow ring) to profile diffusion halos.

Part II — Zernike moments (the math)

Step A · map to the unit disk

Minimum enclosing circle

Per object compute the minimum enclosing circle — center (ci,cj), radius R — then normalize every pixel into the disk. prepare_object_zernike_polynomials · measurement.py:3830

x = (j − cj) / R,    y = (i − ci) / R  → x²+y² ≤ 1

Note: a different center and scale than Part I (MEC center / MEC radius, not farthest-from-edge / edge distance).

Step B · the basis

Orthogonal polynomials on the disk

Indexed by (n,m), n≥0, 0≤m≤n, n−m even (get_zernike_indexes; degree 9 → 30 moments). Each factors into radial × angular. construct_zernike_polynomials · zernike.py:40

Vn,m(ρ,φ) = Rnm(ρ) · eimφ
Rnm(ρ) = Σk=0(n−m)/2 (−1)k (n−k)!k! · ((n+m)/2−k)! · ((n−m)/2−k)! ρn−2k

Computed via a factorial lookup table + Horner scheme; pixels outside the disk are zeroed. construct_zernike_lookuptable · zernike.py:14

Step C · project intensity

The moment = inner product

For each (n,m), sum intensity against the basis (two real sums per object). calculate_zernikes_for_image · _measureobjectintensitydistribution.py:144

vr = Σp I(p)·Re(Vn,m),    vi = Σp I(p)·Im(Vn,m)
Magnitude = √(vr² + vi²) / area    Phase = atan2(vr, vi)

area normalizes for object size, making the magnitude an intensity-density-like, scale-invariant quantity.

Step D · what it means

Rotation-invariant fingerprint

Rotate the object by α: every φ→φ+α, so the moment picks up a pure phase.

An,m → eimα·An,m  ⇒ |An,m| unchanged

n = radial order (radial oscillations). m = angular harmonic: m=0 radially symmetric, m=1 one-sided gradient, m=2 bilobed, m=3 trilobed. Magnitude is invariant; phase is the orientation.

The unifying idea
Both characterize the same internal intensity field. The rings give a localized, directly-readable radial profile — "is the signal central or peripheral, and is each ring symmetric?" Zernike gives a global, smooth, rotation-invariant decomposition by radial and angular frequency — a compact feature vector that detects m-fold angular structure the rings cannot see. They are meant to be used together as complementary descriptions.
Failure mode to watch
Zernike assumes intensity over a filled disk (pixels inside the MEC but outside the object are zeroed). For sparse or branching objects that don't fill their enclosing circle, the low-order moments are dominated by the fill fraction rather than internal structure — they degrade into a roundabout shape descriptor.
