The whole module is an optimization loop driven by TuningEngine.optimize() (_engine.py). One search space is inferred once up front; then each trial repeats the same four moves until the strategy exhausts or the budget caps.

01 — WHAT YOU PROVIDE

User input: the spec, the images, the flags

A run needs three things: a tuning spec (the self-contained recipe), a directory of calibration plates, and optional CLI flags that override the spec or fan the run out over SLURM.

The CLI surface

# Run a spec over an image directory (the engine)
uv run python -m phenotypic.tune run spec.json -i ./plates -o ./out

# Override the strategy / budget on the fly
uv run python -m phenotypic.tune run spec.json -i ./plates \
    --strategy tpe --n-trials 200 --screen

# Distributed: a shared Optuna study + a SLURM worker fleet
uv run python -m phenotypic.tune run spec.json -i ./plates \
    --slurm --n-workers 8 --storage-url postgresql+psycopg://user@host/db

# Infer a reviewable search space from a pipeline (no engine run)
uv run python -m phenotypic.tune auto-space pipeline.json -o ./out

The tuning_spec.json recipe

One round-trippable pydantic model (TuningSpec) carrying every moving part. Knob targets are cross-checked against the live pipeline at construction (out-of-range op, wrong class, missing field — with a did-you-mean).

Calibration plates

Every image under -i loads as a GridImage (arrayed-colony plates). --nrows/--ncols pin a known uniform grid for cell-aware scoring. Unreadable files are skipped, not fatal. A held-out slice is reserved deterministically by content hash.

02 — STAGE ZERO (ONCE, BEFORE THE LOOP)

How a parameter becomes a tunable dimension

infer_search_space() (_search_space/_infer.py) walks the pipeline's pydantic operation fields. Each field becomes a Knob (a tunable dimension) or an Excluded record. Two tiers decide the domain.

Tier 1 — explicit TuneSpec

If a field carries a TuneSpec marker it wins outright: explicit low/high/step/log or categories. A subset assertion enforces TuneSpec ⊆ field bounds — you can never tune outside the operation's own pydantic validation.

Tier 2 — type heuristics

No marker? The field's type decides. Bounded numerics map to their ge/le range; unbounded numerics get a window around the default; open sets (str / Path / ndarray) are excluded. Recurses exactly one level into operation-valued fields.

Field typeInferred domain
boolCategorical(True, False)
Literal[...] / EnumCategorical(choices)
numeric with ge/leIntRange / FloatRange(low, high)
numeric unbounded, default dwindow [d/4, d·4]  (_DEFAULT_UNBOUNDED_FACTOR = 4), stamped needs_review
str / Path / ndarrayExcluded (open set / not scalar-tunable)

The log-scale auto-trip

A range is flagged log=True when it spans enough orders of magnitude — sampling becomes uniform in log space:

unbounded heuristic   high / low > 10  (_LOG_SPAN_THRESHOLD)
explicit bounds      high / low ≥ 100  (_BOUNDED_LOG_SPAN_THRESHOLD)

Conditional knobs (define-by-run). A sub-parameter is only suggested when its parent values match (knob.is_active(chosen)) — an op's knobs enter the space only when that op is actually selected. This is what lets one space describe a pipeline whose shape changes per trial.
03 — DECIDE THE NEXT PARAMETERS

Strategies & samplers

The strategy answers “what to try next.” Four are Optuna samplers (all seeded), plus two zero-dependency homegrown strategies. Multi-objective auto-overrides to NSGA-II.

TPE default

Tree-structured Parzen Estimator. Models the inputs given the outcome p(x|y) and inverts via Bayes. After n_startup random trials it sorts by score and splits at quantile γ: l(x) = density among good trials, g(x) = density among the rest.

EI(x)  ∝  l(x) / g(x)
propose values common among good, rare among bad

CMA-ES

Evolution strategy adapting a covariance matrix over a continuous space. Strong once the space is continuous-dominant (e.g. a post-screening focused round); falls back to independent sampling for categoricals.

GP

Gaussian-process Bayesian optimization — for low-dimensional, expensive evaluations where each trial is costly and the surrogate's uncertainty estimates pay off.

NSGA-II multi-obj

Genetic multi-objective sampler. Auto-selected whenever there are ≥ 2 objectives, regardless of the configured sampler, and pruning is disabled (Optuna pruners are single-objective).

Random no learning

Seeded i.i.d. sampling; register_result is a no-op. Continuous log floats sample as exp(uniform(log low, log high)). A solid baseline and the explore-round workhorse.

Grid exhaustive

Exhaustive conditional Cartesian product (enumerate_grid). Conditional knobs only enter the product when active. Raises on a continuous FloatRange — it is not enumerable.

Deep dive · 3.1

TPE — the density-ratio sampler

TPE is the default because it natively handles our mixed continuous / categorical / conditional space. Instead of modeling the objective p(y|x) directly (as a Gaussian process does), it models the inputs given the outcome p(x|y) and inverts via Bayes. After n_startup_trials random probes it sorts every observed trial by cost and splits them at a quantile γ into two non-parametric (Parzen-window / KDE) densities:

  • l(x) — density of parameter values among the good trials (the lowest-cost γ-fraction);
  • g(x) — density among the rest.

The next candidate maximizes Expected Improvement, which for TPE collapses to maximizing the density ratio:

next θ = argmaxθ   l(θ) / g(θ)   propose values common among good trials, rare among bad ones
Deep dive · 3.2

CMA-ES & NSGA-II — the population samplers

Both evolve a population of candidates generation by generation rather than fitting a per-dimension density. CMA-ES is the single-objective workhorse for continuous-dominant spaces (e.g. a post-screening focused round); NSGA-II is auto-selected the moment there are ≥ 2 objectives.

CMA-ES — covariance-matrix adaptation

It maintains a multivariate Gaussian N(m, σ²C) over the continuous parameters. Each generation samples λ candidates, ranks them by cost, recombines the best μ into a new mean, and adapts the covariance C and step size σ so the sampling ellipse rotates and stretches along the directions that have been paying off — then shrinks as it homes in. Categorical knobs fall back to independent sampling.

m(g+1) = Σᵢ wᵢ · xᵢ:λ  weighted recombination of the top-μ ranked samples
C, σ  adapt  toward the local cost contour  (rank-μ + rank-one update, step-size control)

NSGA-II — non-dominated sorting genetic algorithm

The multi-objective sampler. Each generation it sorts the population into dominance fronts (F₁ = non-dominated, F₂ = dominated only by F₁, …), then selects survivors by rank first and, within a tie, by crowding distance (a diversity term that favors isolated points so the front spreads out). Elitist crossover + mutation breed the next generation. The output is the Pareto front; the run then reports its knee point (§07) as the single recommended config.

rank by dominance: a ≼ b iff a ≤ b on every axis & < on one
tie-break by crowding distance = Σaxes normalized neighbor gap  (keeps the front diverse)
Two-round screening freeze (--screen): an unpruned explore round samples broadly, parameter importance is computed, the least-important knobs are frozen to their best value, and a focused round tunes the reduced space — often switching to CMA-ES now that the space is smaller and more continuous.
04 — RUN ONE PROPOSAL

Evaluation: rung ladder + robust aggregate

This is the heart of Evaluator.evaluate() — where “accuracy over speed” becomes real math. A candidate is scored on a growing ladder of plates, reduced by a spread-penalized median, and cheap losers are killed early.

A

Fidelity ladder (ASHA rungs)

Rather than always scoring every plate, images are scored in growing blocks. Each image is scored once (memoized across rungs).

first rung = max(rung_floor=6, ⌈n / rung_factor=3⌉)
each next  = previous × rung_factor   ···   last rung = all n
too few images for min_rungs=2 → self-disables to one full-fidelity pass
B

Robust per-term aggregation

After each rung, every term's per-image cost values are reduced not by a mean but by a median plus an IQR penalty, then clamped:

term = clamp01( median(b₁…bₖ) + λ · IQR(b₁…bₖ) )   λ = 0.5, IQR = Q75 − Q25

The +λ·IQR term penalizes parameters that work inconsistently across plates — a config brilliant on two plates and terrible on three (high IQR) is dragged toward worse cost and loses to a steady one.

C

Finalize to the objective

scorer.finalize(terms) collapses the term dict to the scalar Optuna minimizes (or a dict for multi-objective). The shared projection is mean(objectives.values()).

D

Pruning decision (between rungs only)

The pruner is Successive Halving / ASHA. At each rung trials are ranked by interim value; only the top 1/reduction_factor (top third) survive — under minimize, the ASHA pruner keeps the lowest-cost third. A clear loser dies after 6 plates instead of wasting the full set.

disabled during explore rounds (unbiased importance) · disabled for multi-objective · grid/random never prune

Failure taxonomy

Won't build

Candidate can't construct → hard failed=True, score floored to 1.0 (worst).

One image raises

That image contributes the worst term (1.0) to every term; the loop continues. Failures honestly drag the aggregate up toward worse cost.

All images raise

Whole-candidate failed=True — feeds the max_failures safety valve.

05 — JUDGE THE RESULT

The four scoring objectives

Every scorer returns named per-image terms as natural values and declares a Sense; the base score_image orients each to cost ∈ [0,1] via to_cost (a HIGHER_BETTER term like Dice is complemented 1−value; a divergence passes through).

A · SupervisedScorer ground truth

Mask tier — region overlap. For each matched predicted/GT pair, Dice or IoU (they rank identically), macro-averaged into term Region:

Dice = 2|A∩B| / (|A|+|B|)
IoU  = |A∩B| / |A∪B|

Matching is greedy by descending IoU; at τ=0.5 the assignment is provably one-to-one. Binary GT is split into per-cell instances on a geometric, detection-independent grid so under-segmentation is scored honestly. Count tier when only counts exist → term CountMAE.

B · ReferenceFreeScorer no GT

Four fixed-normalized [0,1] proxy terms (fixed normalization avoids the “Böck trap” where the optimum migrates):

ShapeRegularitymean(Solidity, Circularity, 1−Eccentricity)
ContrastOtsu between-class ratio η = σ²_B / σ²_T
SizeCV1/(1+CV), CV = σ/μ within replicate groups
Count?threshold-anchored count fold (optional)

Gated by meta-validation: trusted only if Spearman ρ with GT clears ρ ≥ 0.7 (0.8 for unattended). Otherwise it abstains and the engine degrades to QC.

C · QCScorer count-only

The count divergence is the natural value (a loss). Because it is unbounded, the scorer supplies an anchor (the check's fail_threshold) and the base folds it:

metric = |detected − expected| / expected
cost = 1 − exp( −ln2 · metric / thr )

metric 0 → cost 0.0; metric = threshold → exactly 0.5; metric → ∞ → cost 1.0. Averaged across groupby units → term Count.

D · CompositeScorer blend

Each child owns a namespaced prefix (s0., s1.…), is finalized to a per-child cost bᵢ ∈ [0,1], then blended over the study-global active set. Default is the augmented Tchebycheff scalarization (see below). Can also run multi_objective=True to feed NSGA-II a per-child cost vector.

The composite blend — augmented Tchebycheff

The single-objective default. The max makes it conjunctive (the worst axis dominates — every objective must be good); the ρ·Σ augmentation upgrades minimizers from weakly to properly Pareto optimal:

Tᵨ(b) = maxᵢ wᵢ(bᵢ + ε)  +  ρ · Σᵢ wᵢ·bᵢ   (minimize)
T_norm = Tᵨ(b) / Tᵨ(1…1)  ∈  (0, 1]   study-global normalizer → argmin-preserving across trials
utopia z*ᵢ = −ε,  _UTOPIA_EPS = 1e-3,  rho = 0.05  (framework-derived, never user-set)
Never a geometric mean of cost. 0 is the product's annihilator, so one perfect axis (cost 0) would zero the product and dominate — the opposite of the conjunctive property. The compensatory opt-out is blend="weighted_mean" (Σwᵢbᵢ / Σwᵢ), which a strong axis can use to offset a weak one — but it cannot reach non-convex-front compromises, which is why it is not the default.

06 — WHICH KNOBS MATTERED

Parameter importance

Computed after the study in compute_param_importance_report with capability dispatch (never a type check). A knob is “important” if changing it moves the objective a lot.

fANOVA preferred

Functional ANOVA. Fit a random-forest surrogate of score = f(params), then decompose the surrogate's prediction variance into per-parameter (and interaction) contributions. A parameter's importance = the fraction of total objective variance explained by varying it.

accounts for interactions · interactions_estimated = True

RF-permutation fallback

Used for per-objective requests or when no native model exists. Fit RandomForestRegressor(n_estimators=200), then permutation_importance(n_repeats=10): the drop in model accuracy when one parameter's values are shuffled. Categoricals are one-hot encoded and summed back.

main effects only · interactions_estimated = False · {} below 2 usable trials
07 — MULTIPLE OBJECTIVES

Pareto math: dominance & the knee point

When the scorer is multi-objective, directions become ["minimize"] * n, NSGA-II is forced, pruning is off, and trials carry a per-objective vector.

Dominance

a dominates b iff a is ≤ b on every axis AND strictly < on at least one. The Pareto front is all non-dominated trials (ties deduplicated).

Knee point — picking one

Draw the chord between the lexicographic extremes lo = min(vectors) and hi = max(vectors); the recommended trial is the one with maximum perpendicular distance to that chord — the elbow where you stop gaining on one objective without sacrificing another.

exact for 2 objectives · heuristic for ≥ 3
A multi-objective run additionally publishes deliverables/pareto/: the front parquet, one best_<objective>.json per axis, and overwrites best_pipeline.json with the knee. A single-objective run's empty front makes this a no-op (the back-compat lock).
08 — DO YOU TRUST THE WINNER?

The held-out generalization check

A held-out split is reserved deterministically by a 3-tier policy, the winner is re-evaluated on it, and the gap is reported. Report-only — the winner never changes.

The 3-tier split policy

  1. Skip if fewer than min_heldout_plates (default 6) plates.
  2. Hold out a whole group if ≥ 2 groups exist — the strongest cross-batch test.
  3. Else hold out ceil(held_out_fraction · n) (default 0.2) within-group.

The seed is folded from a SHA-256 content hash of sorted plate names, so the same dataset always yields the same split regardless of resume order.

The overfit gate

The standard loss-space generalization gap. Because cost is a loss, this is direction-correct by construction — no custom sign flip:

abs_gap = heldout_cost − cal_cost   positive = overfit
rel_gap = abs_gap / max(1 − cal_cost, _GAP_EPS≈0.02)   on the goodness-equivalent
flag  ⟺  rel_gap > rel_margin (0.15)  AND  abs_gap > abs_margin (0.05)

The relative term divides by the goodness-equivalent 1 − cal_cost so a near-perfect calibration (cost ≈ 0) doesn't explode.

What each artifact answers

best_pipeline.json

The tuned ImagePipeline, ready to feed the forward CLI. The knee point for a multi-objective run.

trials.parquet

The full study journal — score, terms, objectives, gap, suspicious, failed/pruned flags per trial. The audit trail.

param_importance.json
