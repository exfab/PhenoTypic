Cross-domain analog · transfer to fungi

Plant root system architecture → fungal branches

Root System Architecture (RSA) solves the exact problem we have: a 2D projection of an overlapping branched net. A photographed root system is a tangle of laterals crossing one another, just like dense hyphae on agar. RSA's answer — fit each root as a least-cost A* path from apex to seed — is the same algorithm PhenoTypic's retracing module uses (multi-source Dijkstra in branch_pathfinding). That makes RSA the closest analog in the whole catalog.

Topology: herringbone vs dichotomous

Regime A · tree🔴 A-fragile

Fitter's topological index contrasts two extremes. Herringbone (TI≈1): laterals branch only off the main axis. Dichotomous (TI≈0.5): branching is distributed, every branch splits again. Same tip count, opposite architecture.

→ FungiDistinguishes apical-dominant hyphal trees from richly dichotomous tip-splitting morphotypes — but needs a clean parent/child graph, so it sits behind retracing.
SourceFitter 1987; Delory 2016 (archiDART)

A* path recovery through a crossing

Regime A🟡 A-feasible

RootNav makes each pixel cheap-to-traverse where it looks root-like, then runs A* from apex to seed. The path glides through a crossing because the straight continuation is cheaper than turning — a crossing is traversed, not mis-read as a branch.

→ FungiPhenoTypic already runs multi-source Dijkstra least-cost paths; the borrowed refinement is direction-continuity edge pairing at junctions.
SourcePound 2013 (RootNav, EM + A*)

RootPainter corrective loop

deep-seg🟡 human-in-loop

Train a CNN on occlusion-heavy images without a big pre-labelled set: the model predicts, a human paints only the fixes on its mistakes, and the model retrains on those corrections — converging on a usable segmenter fast.

→ FungiA GUI corrective-annotation affordance for the ambiguous-junction minority — fungal edge precision (~28% in MyceliumSeg) is the documented bottleneck this targets.
SourceSmith 2022 (RootPainter); Wang 2025 (MyceliumSeg)

The occlusion problem itself

Regime A🔴 ambiguous

In a flat photo, two roots crossing and one real branch produce the identical degree-4 / degree-3 pixel pattern. Naive skeleton degree-counting cannot tell them apart — this is the core failure mode RSA (and our retracing) must engineer around.

→ FungiThe hyphal crossing-vs-anastomosis problem verbatim. Resolve degree-4 nodes by smallest-turning-angle continuity; X-ray-CT / RSAtrace3D physically removes the ambiguity when throughput allows.
SourcePound 2013; Teramoto 2020 (RSAtrace3D)

Signature RSA metrics & the occlusion toolkit

One card per signature metric or method. Definition → how it works (illustration) → what it transfers to fungi + source. RSA splits cleanly into whole-system silhouette metrics (occlusion-proof) and graph/topology metrics (retracing-gated), plus a dedicated occlusion toolkit.

Total root length & convex hull / solidity

Regime B🟢 B-robust

Two paired descriptors. Total root length sums all traced segments (graph-level). The convex hull and its solidity (network area ÷ hull area) describe the foraged territory and how densely it is filled — both readable from the mask alone.

→ FungiSolidity & hull are already 🟢 ship-now colony descriptors; total hyphal length is the headline 🟡 retracing-gated number.
FromRootsMycologyNeuro
SourceGalkovskyi 2012; Seethepalli 2021 (RhizoVision)

Lateral density & emergence angle

Regime A🔴 A-fragile

Lateral density = laterals per unit length of parent root; emergence angle = the insertion angle of each lateral off its parent. Together they describe how aggressively and at what geometry a root forages sideways.

→ FungiBranching frequency φ and mean branch angle are the direct hyphal analogs (catalog Family F/G) — both flagged 🔴 because angles collapse at overlap.
FromRootsMycologyNeuro
SourceLobet 2011 (SmartRoot); Delory 2016

Topological indices (magnitude, altitude, PE, TI, Strahler/Shreve)

Regime A · tree🔴 A-fragile

A whole vocabulary on the rooted tree: magnitude = #tips, altitude = links in the longest tip→base path, total exterior path length (PE) = Σ over all tips of path-to-base, TI = log-altitude vs log-magnitude slope, plus Strahler/Shreve ordering of segments.

→ FungiStrahler order, bifurcation ratio, magnitude/altitude/PE all map onto the hyphal tree (Family F) — powerful but loop-breaking under anastomosis, so 🔴 / retracing-gated.
FromRootsGeomorphNeuro
SourceFitter 1987; Delory 2016 (archiDART); Strahler 1957; Shreve 1966

Interbranch distance & tortuosity

Regime A🟡 A-feasible

Interbranch distance = arc length between consecutive branch points along a root. Tortuosity = path length ÷ straight-line distance (≥1) per segment — how much a root wanders versus going straight.

→ FungiMean internode distance & mean tortuosity are 🟡 in the catalog — robust per-branch once retracing produces a correct segment.
FromRootsVascularNeuro
SourceLobet 2011 (SmartRoot); Nunez-Iglesias 2018 (skan)

Fractal dimension & lacunarity

Regime B🟢 B-robust

When roots overlap and can't be separated, RSA falls back to mask descriptors. Box-counting D = slope of log N(ε) vs log(1/ε) (space-filling); lacunarity Λ = gliding-box variance/mean² of occupancy (gappiness) — separates two systems that share the same D.

→ FungiIdentical to the catalog's highest-value 🟢 additions (COMPLEXITY): mass/surface FD + lacunarity are the safe backbone for confluent mycelium.
FromRootsMycologyPhysics
SourceBouda 2016 (box-counting roots); Plotnick 1996 (lacunarity)

Occlusion toolkit · deep segmentation (RootNav 2 / SegRoot)

deep-seg🟡 learned

When hand-tuned thresholding fails on dense tangles, RSA went deep. RootNav 2.0 replaces the manual feature step with a multi-task CNN that emits roots + tips + seeds; SegRoot is an encoder–decoder that segments roots from soil background end-to-end.

→ FungiA U-Net/multi-task front-end for dense mycelium; emitted tip/seed channels seed the retracing module's source set.
FromRootsVascularNeuro
SourceYasrab 2019 (RootNav 2.0); Wang 2019 (SegRoot)

Occlusion toolkit · 2D-vs-3D (X-ray CT / RSAtrace3D)

Regime A🟡 trades throughput

The cleanest fix for projection occlusion is to remove the projection. X-ray CT images the root system volumetrically; RSAtrace3D traces it slice-by-slice in 3D, where two roots that overlap in a photo are physically separated in depth.

→ FungiThe confocal / light-sheet route for mycelium — physically removes overlap when throughput permits; the catalog's #7 toolkit answer.

SourceTeramoto 2020 (RSAtrace3D)

RSA's verdict, ported to hyphae

RSA has spent two decades at exactly our operating point — a flat photo of an overlapping branched net — and converged on a clear engineering doctrine. Four lessons transfer directly:

  • Invest modelling effort in segmentation, not post-hoc cleanup. Deep nets (RootNav 2 / SegRoot) plus interactive correction (RootPainter) are where the accuracy comes from — getting "rootness" right up front beats any amount of downstream graph repair.
  • Recover topology by path-following, not naive skeleton degree-counting. Trace each filament as a least-cost A* path so a crossing is traversed; degree-counting a projected skeleton invents branches at every overlap.
  • Lean on whole-system silhouette metrics that dodge occlusion. Convex hull, solidity, fractal dimension and lacunarity never separate strands, so the tangle never breaks them — they are the safe backbone when tracing is uncertain.
  • Accept human-in-the-loop as the accuracy ceiling. Every RSA tool that reaches production trust keeps an operator on the ambiguous-junction minority; trustworthy topology is co-authored, not fully automated.
