Neuroscience → fungal branches

Neuroscience has spent seventy years quantifying branched arbors, and the result is the richest branch-tree vocabulary of any field — Sholl radial density, the L-Measure morphometric lexicon, branch-order theory, and TMD persistence fingerprints. A dendritic arbor and a hyphal network are the same object: a rooted tree of segments that splits, tapers, and fills space from a single origin. What transfers is twofold — a graph vocabulary for when the retracing module resolves branches, and a whole-field fallback (radial density, fractal, persistence) for when dense confluent mycelium refuses to be separated. Both halves drop straight onto a colony imaged from its inoculum.

Sholl analysis & its variants

Regime B🟢 B-robust

Centre concentric rings on the soma and count how many times the arbor crosses each ring → the Sholl profile N(r). Variants read off it: critical radius rc (radius of peak N), max intersections Nm, enclosing radius (extent), the regression coefficient k (semi-log decay slope), a polynomial decomposition, and the ramification index (Nm ÷ primary-process count). It needs no branch separation — only crossings.

RegimeB · radial density on the mask
Inputbinary mask + origin (inoculum/centroid)
→ FungiConcentric hyphal-density rings from the inoculum — ShollMaxIntersections, ShollCriticalRadius, ShollEnclosingRadius, ShollRegressionCoefficient (ramification index 🟡, needs a primary-hypha count).

Centrifugal & Horton–Strahler branch order

Regime A🔴 A-fragile

Two ways to rank where a segment sits in the tree. Centrifugal order starts at 1 at the root and increments by 1 at every bifurcation outward — depth from the origin. Horton–Strahler order starts at 1 at every terminal tip; when two segments of order k meet, the parent becomes k+1 (otherwise it keeps max). The Strahler spectrum feeds the bifurcation ratio Rb (Horton's law).

RegimeA · rooted graph (tree)
Inputskeleton + graph with parent/child
→ FungiBranch hierarchy of a retraced hyphal tree — StrahlerMaxOrder + BifurcationRatio; centrifugal order indexes depth from the inoculum. Gated on retracing closing loops cleanly.

L-Measure morphometric vocabulary

Regime A🟡 A-feasible

L-Measure is the standard lexicon of per-branch geometry. Four members transfer cleanly: bifurcation angle (local — at the node — vs remote — to a downstream reference point), partition asymmetry |nL−nR|/(nL+nR−2) per node, and contraction / tortuosity = geodesic path length ÷ Euclidean endpoint distance (≥ 1, straightness of a segment).

RegimeA · per-branch geometry
Inputskeleton graph with node geometry
→ FungiPer-hypha geometry on a retraced network — MeanBranchAngle, PartitionAsymmetry, MeanTortuosity; tortuosity is the most overlap-tolerant (per-branch once traced).

TMD persistence barcodes

Regime A🟡 A-feasible

The Topological Morphology Descriptor walks a distance function (usually radial) up a rooted tree and records, for every branch, a birth (at its tip) and a death (at the bifurcation where it merges into a longer branch). The set of birth–death pairs is a persistence barcode / diagram — vectorizable into a persistence image. It is order-invariant and, crucially, degrades gracefully as tracing error rises.

RegimeA · rooted tree → topological summary
Inputrooted graph + a distance function
→ FungiOrder-invariant network fingerprint for clustering colony morphotypes — TmdPersistenceImage; the same persistence primitive as astronomy's DisPerSE skeleton.
FromNeuro
SourceKanari et al. 2018

Dense-tracing toolkit

Regime A🟡 reconstruction

The reconstruction front-end neuroscience built for tangled, overlapping arbors — the part that produces the graph the metrics above consume. Four members transfer directly: flood-filling networks (FFN — recurrent per-process re-segmentation), U-Net / DeepNeuron (learned dense segmentation), APP2 (gray-weighted distance-tree tracing), and SNT A\* minimal-path (least-cost path so a crossing is traversed, not branched).

Neuroscience's lesson: separate better, or don't separate at all

Neuroscience learned the hard way that per-process graph metrics collapse in dense tissue — count tips, junctions, angles, or loops in a tangle of overlapping neurites and the numbers become artifacts of where strands happen to touch. The field's response splits cleanly in two, and both halves transfer directly to dense hyphae:

  • Reconstruct harder. Invest in better tracing so the graph is real before you measure it — flood-filling networks, U-Net/DeepNeuron segmentation, and A\* / least-cost-path tracing that traverses a crossing instead of reading it as a branch. This is the same backbone branch_pathfinding already runs; the gains come from a vesselness cost term, degree-4 junction resolution, and DIADEM-style validation.
  • Or never separate. Fall back on whole-field descriptors that need no per-branch isolation — Sholl radial density, fractal dimension, convex-hull occupancy, and TMD persistence (which degrades gracefully even on an imperfect graph). These are the ship-now layer for confluent mycelium.

Three analog fields — neuroscience, plant RSA, and vascular — reached this same conclusion independently: when structures can't be separated, you fall back to fractal / lacunarity / density / radial / convex-hull descriptors. Persistence is the recurring noise-robust primitive across neuroscience (TMD) and astronomy (DisPerSE).
