Radial / Sholl-type density profiles

Treat the inoculum (or mask centroid) as the colony "soma" and sweep concentric rings outward. How many hyphae cross each ring, and how density falls off with radius, reads where the growth front is and how compact the core is — all from the binary mask, never separating one hypha from the next.

How a radial profile is built

Center on the colony origin, lay down concentric rings, and read the resulting profile of ring crossings and annular density. Four panels: rings → N(r), landmarks on N(r), density falloff, and the core/annulus split.

Why radial profiles survive dense, overlapping, low-resolution hyphae

Sholl-style radial profiles are computed from the mask centered on the colony origin, so they capture "where is the growth front / how does density fall off" without isolating individual hyphae. Counting ring crossings and annular occupancy never asks which strand is which — it only asks how much mask sits at each radius — so the readout degrades gracefully on confluent, crossing, coarse mycelium instead of failing the way tip/junction counting does.

Sholl intersection profile N(r)

Regime B🟢 B-robust

The number of times the mask crosses each concentric ring centered on the colony origin, plotted against radius. The whole radial signature of the colony in one curve.

Inputbinary mask
FromNeuro
SourceSholl 1953; Ferreira 2014
Output metric
Value
N(r) — mask crossings counted on each concentric ring vs radius
Units
count per ring (integer ≥ 0) plotted against radius r in px (µm)
Reads as
tall sustained profile = many strands persisting outward; steep drop to 0 = compact silhouette confined near the origin
Variables
N(r)
number of mask crossings on the ring of radius r
r
radial distance from the colony origin (pixels)

Sholl regression coefficient k

Regime B🟢 B-robust

The slope of N(r) plotted on a semi-log (or log–log) axis — the rate at which hyphal density declines with radius. A steeper k means a faster thinning toward the margin.

Ramification index

Regime B🟡 A-feasible

Max intersections Nm divided by the number of primary hyphae leaving the origin — how much the colony branches relative to how many trunks it started with.

Inputmask + stem count
FromNeuro
SourceFerreira 2014
Output metric
Value
RI = Nm ÷ primary — peak crossings per trunk leaving the origin
Units
dimensionless ratio (≥ 1)
Reads as
high RI = few trunks fanning into many outer crossings, a bushy branched outline; RI ≈ 1 = little multiplication, near-radial spokes
Variables
Nm
max intersections — the peak height of N(r)
primary
number of primary hyphae leaving the origin (trunk count)

Radial mass distribution / density falloff

Regime B🟢 B-robust

The occupied-pixel fraction in each concentric annulus, plotted against radius — the core-to-hairy density profile that says how filled the colony is at every distance.

Inputbinary mask
FromMycologyRoots
SourceTucker & Thomas 1992
Output metric
Value
ρ(r) — occupied-pixel fraction of each annulus vs radius
Units
dimensionless 0–1 per ring, plotted against radius r in px (µm)
Reads as
high, flat ρ(r) = a solidly filled disc at every radius; sharp drop = dense core fading to a sparse, hairy margin
Variables
r
radial distance from the colony origin (pixels)
occupied fraction
mask pixels ÷ annulus area, measured per concentric ring, plotted against r

Core/annulus split & relative annular diameter (RAD)

Regime B🟢 B-robust

(d_total − d_core) / d_total — the fraction of the colony radius that is loose outer zone rather than compact core. A single dispersed-vs-pelleted number.

Inputmask / grayscale
FromMycology
SourceVeiter 2018
Output metric
Value
RAD = (d_total − d_core) ÷ d_total — fraction of the radius that is loose outer zone
Units
dimensionless 0–1
Reads as
RAD → 0 = compact pellet, almost all core; RAD → 1 = thin core inside a broad diffuse/hairy annulus
Variables
RAD
relative annular diameter = (d_total − d_core) ÷ d_total; 0 = compact pellet, 1 = diffuse/hairy
d_total
full diameter of the colony's total extent
d_core
diameter of the dense compact core

Bushiness

Regime B🟢 B-robust

The maximum ÷ median strand-crossing count over a family of scan lines — how peaked the densest swath is relative to a typical one. High when growth clumps into a few thick bands.

Inputbinary mask
FromRoots
SourceGalkovskyi 2012
Output metric
Value
B = max ÷ median — busiest scan-line crossing count over the typical one
Units
dimensionless ratio (≥ 1)
Reads as
high B = growth clumps into a few thick bands, a peaky uneven silhouette; B ≈ 1 = crossings spread evenly across scan lines
Variables
bushiness

max
crossing count of the busiest scan line
median
crossing count of the typical (median) scan line
