Per-branch geometry

The metric vocabulary of a single traced filament — how long each segment is, which way it bends, the angle it leaves its parent at, and how thick it is along the way. Every value here is read off a correct local skeleton, so the family is measurable only where individual hyphae are actually resolved.

Branch / segment length distribution

Regime A🟡 A-feasible

The arc length of every inter-node segment, summarised as a mean, a maximum and a histogram. A segment is one skeleton edge running tip-to-junction or junction-to-junction; the spread of those lengths distinguishes sparse, long-stride hyphae from finely subdivided ones.

Units
px (or µm)
Reads as
↑ Lseg = longer, sparser strides between nodes; ↓ = finely subdivided, many short segments

Internode / inter-branch distance

Regime A🔴 A-fragile

The arc length of hypha between two consecutive branch points. Short internodes mean frequent, densely packed branching; long internodes mean a sparse, exploratory growth habit. Measured along the centre line, not as a straight-line gap.

↑ dinternode = sparse, widely-spaced branching; ↓ = frequent, densely packed branch points

Branch / bifurcation angle (local & remote)

Regime A🔴 A-fragile

The angle between parent and daughter at a branch point. The local angle uses the first few pixels leaving the node; the remote angle uses the direction toward the next node downstream, so it reports the daughter's settled heading rather than its launch.

Bifurcation tilt & torque

Regime A🔴 A-fragile

Tilt is the angle between the parent and the plane the two daughters span; torque is the twist between one bifurcation and the next along a path. Both are genuinely three-dimensional descriptors and have no stable meaning in a flat projection.

Input3-D skeleton graph
FromNeuro
SourceScorcioni et al. 2008
Output metric
Value
tilt, torque — parent-to-daughter-plane angle, and its twist between successive nodes
Units
degrees (both)
Reads as
↑ tilt = daughter plane leans further off the parent axis; ↑ torque = plane spins more sharply node-to-node (0° = coplanar, untwisted)

Partition asymmetry

Regime A🔴 A-fragile

At each bifurcation, how lopsided are the two daughter subtrees? Computed as |nL−nR| / (nL+nR−2) over the tip counts each branch ultimately carries — 0 for a perfectly even split, near 1 when one daughter owns almost the whole subtree.

Caulescence / tree asymmetry

Regime A🔴 A-fragile

How strongly a single dominant main path runs through the tree. High caulescence means one near-straight backbone with small laterals hanging off it (a stem-and-side-branch habit); low caulescence means repeated even forks with no privileged axis.

Tortuosity / contraction

Regime A🟡 A-feasible

How much a branch wanders: the path length traced along the hypha divided by the straight-line Euclidean distance between its endpoints. Always ≥ 1 — exactly 1 for a ruler-straight segment, rising as the hypha meanders.

FromMycologyNeuroRootsVascular
SourceNunez-Iglesias et al. 2018
Output metric
Value
τ — tortuosity: path length ÷ straight-line Euclidean distance between endpoints
Units
dimensionless (≥ 1)
Reads as
↑ τ = wavier, more meandering hypha; τ=1 = ruler-straight segment
Variables
τ
tortuosity: path length ÷ Euclidean distance (dimensionless, ≥ 1)
path length
arc length traced along the hypha between its endpoints (pixels)
Euclidean
straight-line distance between the two endpoints (pixels)

Tortuosity variants (DM / ICM / SOAM / ∫κ²)

Regime A🟡 A-feasible

Four formal ways to score the same waviness: DM distance-metric (path÷chord), ICM inflection-count, SOAM sum-of-angles along the path, and ∫κ² the integrated squared curvature. Each weights small kinks versus broad bends differently.

Hyphal width / diameter

Regime A🔴 A-fragile

The thickness of a hypha, read as the distance-transform radius at each skeleton point — the distance from the centre line to the nearest mask edge, doubled. At a few pixels across, every quantisation error is a large fraction of the value.

Bin total length (or area) by width thresholds, separating fine exploratory hyphae from thick transport cords / rhizomorphs. A coarse, robust use of the width field that tolerates more noise than any single per-pixel diameter.

Taper rate

Regime A🔴 A-fragile

The gradient of diameter along a hypha, from base toward tip. A near-zero taper means a uniform tube; a steep taper means the hypha narrows as it extends. Computed as the slope of width vs arc length.

Reads as

Rall / Murray ratio & junction exponent

Regime A🔴 A-fragile

How daughter diameters relate to the parent at a junction: (d₁ʳ + d₂ʳ) / d₀ʳ, plus the exponent x solving d₀ˣ = d₁ˣ + d₂ˣ (an optimal-transport value near 3). Diameters enter cubed, so tiny width errors blow up — the most diameter-noise-sensitive metric in the family.

Units
dimensionless (x typically ≈2–3)
Reads as
↑ x = parent much thicker than the daughters it splits into; x≈3 = area-preserving cubic split (very diameter-noise-sensitive)

Surface area / biovolume

Regime A🔴 A-fragile

Treat each segment as a tapering tube (a frustum) of known length and end radii, then sum the lateral surface and the enclosed volume across the network — a geometric estimate of total wall area and cytoplasmic biovolume.

Inputskeleton + radii
FromMycologyNeuroVascularRoots
SourceScorcioni et al. 2008
Output metric
Value
S, V — network lateral surface area and enclosed biovolume, summed over per-segment frusta
Units
S in px² (µm²); V in px³ (µm³)
Reads as
↑ S, V = longer and/or thicker network overall; the S:V ratio rises as strands thin toward fine hyphae
Variables
r₀
radius at one end of the segment's frustum (pixels)
r₁
radius at the other end of the segment's frustum (pixels)
Σ
sum of frustum lateral surface and enclosed volume over all segments in the network

Why this is the most resolution-sensitive family

Every metric here is read off a correct local skeleton. Angles, widths and taper all collapse exactly where the image is hardest: near crossings and overlaps the skeleton sprouts false junctions, and at the few-pixel widths typical of low-resolution agar plates a single quantisation step is a large fraction of the measured value. Diameter-derived quantities are worst — Rall/Murray raises width to ~3, so sub-pixel error dominates the answer.

Treat per-branch geometry as feasible only on sparse, well-resolved regions of a plate — or downstream of the retracing module (sdk_/branch_pathfinding), once it traces filaments through crossings and a DIADEM-style validation gate certifies the local skeleton. Outside those conditions, fall back to the mask-level Regime-B descriptors, which never separate branches and so never inherit this fragility.
