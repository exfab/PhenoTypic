01 · the state of the objective

The scorer works. The gate in front of it never opens.

Four proxy terms are implemented, each fixed-normalized to [0,1] higher-is-better. No production sweep has ever tuned against them: the meta-validation gate that certifies the proxy against ground truth has no ground truth to read, and phenotypic-tune run raises rather than proceed uncertified. The gate is not airtight — TuningEngine.optimize() never checks it for a non-composite scorer — but nothing in the CLI reaches that door.

Two different things are both called QC here

Seven checks under analysis/qc/ are reference-free in the no-ground-truth sense, and every one of them judges the measurement table, never the segmentation. They cannot tell you a mask is wrong — only that the numbers it produced disagree with each other, or with a layout you supplied.

02 · the shared blind spot

A colony that was never detected produces no evidence anywhere

Three of the four built terms read the measurement frame; the fourth reads the image's histogram. All four therefore score the objects that exist. Miss a colony entirely and every term is content — the surviving masks are still round, still uniform in size, still well separated from agar.

03 · what each candidate measures

Twelve quantities, drawn

Every metric here is a different answer to one question: what can you measure about a mask when you have no correct mask to compare it against? Each figure shows the quantity being computed and, beside it, the failure that moves it. Nothing below is implemented — these are the options.

All twelve unbuilt candidates, in one place

One row each: the mechanism reduced to its essential mark, what the metric actually measures, and a key to every symbol in its formula. Follow a name for the full figure and its caveats.

Weszka–Rosenfeld busyness A.2

busyness = Σ off-diagonal GLCM entries — the object↔background adjacencies

Counts how often the image flips between object and background across adjacent pixels, in one cheap pass over the co-occurrence matrix. A clean rim crosses rarely; a speckled or shattered mask crosses constantly. It scores the mask's compactness and nothing else — no region statistics, no colour. Because it needs a threshold value, it can only evaluate segmentations a threshold already reduced to two levels. Lower is better; the catalogue supplies no normalizer, so treat the scale as unbounded rather than as a fraction.

Borsotti Q A.5

Q(I) = √N / (1000·S_I) · Σⱼ [ e²ⱼ/(1+log Sⱼ) + (N(Sⱼ)/Sⱼ)² ]

The consensus best of the F-family, and the only classic here that charges for both colony failure modes with one number. The first term inside the sum rises when a region is large and internally heterogeneous — a merged doublet. The second rises when many regions share the same area, which is the signature of noise shattering. Smaller is better. Its brittleness is that the same-area term depends on exact area coincidences, so it is sensitive to quantization, and it can misrank a plate whose colonies genuinely vary in size across a growth timecourse.

Zeboudj contrast C(I) A.6

C(Rᵢ) = 1 − Iᵢ/Eᵢ when 0 < Iᵢ < Eᵢ (= Eᵢ if Iᵢ = 0, else 0) ; C(I) = (1/A) Σᵢ Aᵢ·C(Rᵢ)

The best-balanced classic single score for colonies: it couples interior uniformity and boundary separation into one normalized number and, unlike Otsu, it is spatially aware. For every pixel it takes the maximum contrast to its neighbours — inside the region for Iᵢ, across the boundary for Eᵢ. A uniform colony with a crisp rim gives a small Iᵢ over a large Eᵢ, so C approaches 1. Regions are area-weighted, so real colonies dominate specks. Higher is better. The primary source is an untraceable 1988 PhD thesis, so every published form of this reaches us second-hand.

Entropy metric E A.7

E = H_ℓ(I) + H_r(I) — smaller is better

The one genuinely parameter-free classic: no magic constant, no free weights. A coding-theory argument balances region uniformity against region count. Region entropy falls toward zero as you over-segment, because each tiny fragment is trivially uniform, while layout entropy rises with the number of regions. Their sum therefore has a minimum somewhere between merging and shattering, and no tuning constant is needed to find it. Its blind spot is spatial: layout entropy depends only on the size distribution, so two segmentations with identical size histograms and completely different arrangements score the same. Pair it with a contrast term.

q-statistic B.5/B.9

q = 1 − (within-strata SS / total SS) — bounded [0, 1], higher is better

The catalogue's pick for the cleanest single reference-free “is this partition good?” score for colonies. Treat each colony mask as a stratum: if the strata really capture the image's structure, almost all intensity variance lies between them and little remains within, so q approaches 1. A mask that cuts through uniform agar leaves large within-stratum variance and q falls. It reads exactly like R² in a one-way ANOVA with the partition as the sole predictor. The property that matters for a tuning engine is that it is bounded by construction — no min–max normalization over the swept set, so no Böck instability.

FGS — WV + DTNP B.7

WV = (Σ aᵢ·vᵢ) / (Σ aᵢ) ; DTNP = mean difference between each object's pixels and the ring Bᵢ(d) \ objectᵢ

Replaces Moran's-I-over-a-region-adjacency-graph with a far cheaper trick: enlarge each object's bounding box by d, remove the object, and compare the object's pixels against the surrounding ring. No adjacency graph is built at all, which is the whole point of the method. Sparse colonies on agar are the ideal case. In a dense array the ring reaches past the gap and catches the neighbouring colony, so d has to be sized to the colony spacing rather than left at the paper's value. The catalogue verified the ring mechanism from full text but never transcribed the DTNP closed form, so nothing here is its equation.

UOA — under/over-segmentation aware B.6

per segment: H(Rᵢ ∪ Rⱼ) ≤ δ → over-segmented ; H(Rᵢ) > δ → under-segmented

The only metric here that tells you which way a segmentation is wrong, and where. It asks two independent questions of every segment against the same threshold. If merging with a neighbour would still leave something homogeneous, the pair was split — over-segmented. If the segment is internally heterogeneous standing alone, it swallowed something — under-segmented. The two directions are never conflated per segment, so the output is a per-colony diagnosis rather than a score. That suits arrayed plates directly, because “merged doublet” and “split colony” are exactly the two failure modes, and the grid supplies an expected colony size from which to set δ.

EVI — edge validity index B.8

EVI = agreement between segment boundaries and a multi-scale edge map

Asks a question the GS and FGS families never ask: does the mask boundary actually sit where the image has an intensity edge? Compute an edge response — Prewitt at several scales in the original — and measure how well the mask contours coincide with it. A contour eroded or dilated away from the true rim scores low even when the region it encloses is still round and internally uniform, so it catches a class of error that shape, size and homogeneity terms all pass. Higher is better. Yu's own pipeline fuses it with two other terms and wraps it in SAR-specific Gamma/speckle machinery that does not transfer; the idea does.

CSE coverage metrics C.1

FFC = |masks ∩ foreground| / |foreground|

The transferable half of the only peer-reviewed, fully reference-free cell-segmentation suite. FFC asks what share of the image's foreground the masks actually claim, which is the one question none of PhenoTypic's four built terms can answer — they all score the objects that exist, so a colony never detected produces no evidence anywhere. The asymmetry is the useful part: a missed colony removes numerator area and FFC falls, while a mask bleeding onto bare agar adds pixels that are in neither term. Read that precisely, though — a mask swallowing the whole plate scores 1.0, so FFC has to be paired with a term that charges for spill.

Cellpose flow error new · 08-28

err = mean[ (dP_masks − dP_net/5)² ] per label ; drop the mask when err > flow_threshold = 0.4

The most conceptually transferable per-instance confidence in the survey: a model checking its own output for self-consistency, with no ground truth anywhere in the signature. Recompute the flow gradients that the predicted labels imply, then take the per-mask mean squared error against the flows the network itself predicted. Where the two disagree, the mask is not something the model actually believes in, and it is deleted outright. The prerequisite is the whole difficulty for us: it consumes a dense per-pixel field, and Otsu, watershed and hysteresis emit no field to disagree with.

Reverse Classification Accuracy D.1–D.2

predicted DSC = max over the reference database of the reverse classifier's accuracy

A genuinely clever trick: treat the prediction as if it were ground truth, train a segmenter on it, and see how well that segmenter does on images you do have labels for. If the prediction was good, the classifier trained on it will also segment the reference images well. Reference-free at test time — but not annotation-free overall, because it needs an annotated reference database at inference, which is the thing this page exists to avoid. Its aggregate numbers are excellent and its behaviour on already-good masks is not: threshold accuracy collapses on exactly the near-perfect regime where well-imaged plates sit.

Learned Dice regression D.3

predicted DSC = f(image, candidate masks) — a 50-layer 3D residual network

Skip the reverse classifier entirely and regress quality directly: feed the image and its candidate masks to a CNN and have it output the predicted Dice. Four orders of magnitude faster than RCA, and reference-free at inference. The cost sits at training time, where the labels can come either from manual annotation or, more cheaply, from RCA — a substitution that multiplies the error four- to fivefold. For PhenoTypic the interesting variant is neither: corrupt clean synthetic masks in known ways and the true overlap is known exactly, so the training label is a by-product of the corruption rather than a human.

05 · how this goes wrong quietly

Four traps, one refuted claim

Each of these produces plausible output rather than an error. The first is the one that bites a tuning engine specifically, because a tuning engine is a grid sweep.

silent

CSE degrades quietly on one channel

functions.py::cell_type() runs k-means on an (n_cells × n_channels) matrix. With a single channel the first PC trivially explains 100% of the variance — pip-install it, point it at a plate, and it returns plausible numbers that mean nothing. It also wants a paired nucleus-mask channel. Port the coverage subset deliberately; refit the PCA.

wrong regime

RCA fails exactly where our data lives

Aggregates look excellent — 95–99% accuracy, r ∈ [0.95, 0.99]. But on complex-shaped and already-good masks it systematically under-predicts Dice: threshold accuracy collapses to 0.454 (RF) and 0.051 (CNN) for LV myocardium. Well-imaged agar plates are the near-perfect-mask regime — which rules it out as a sweep objective on its own. A reported ~11 min/case (approximate; see the figure) is a second, independent reason, and it also needs an annotated GT reference database at inference — the very thing this page exists to avoid.

contradictory

CellProfiler's polarity disagrees with itself

The Methods in Molecular Biology chapter says a lower power-spectrum slope means more blur; CellProfiler's own docs say a higher one does. FocusScore and LocalFocusScore are given opposite directions too. Re-derive every sign from measureimagequality.py before wiring a threshold. (Medium confidence — 2–1 vote.)

untested

Every number here is from another domain

MAE 0.031, r = 0.83, ~11 min/case (itself approximate), flow_threshold = 0.4 — all from 3D cardiac MR, multiplexed tissue microscopy, or fluorescence cell imaging. No cited source evaluates any of these metrics on binary or instance colony masks on agar. Re-derive locally before trusting one.

Refuted — do not cite

“In-Context RCA reduces cost to 0.70 s (UniverSeg) / 0.37 s (SAM 2), ~85× and ~162× faster than classical RCA.” Killed 1–2 in adversarial verification. The direction of that work — replacing per-test-image training with in-context segmentation — is real; those specific speedups are not verified.

06 · the unblock route

One corpus opens the gate and trains the regressor

Ordered by value per unit of work. The first item is a precondition for everything else: no amount of new metric work matters while availability() returns False.

  1. Unblock the meta-validation gate

    Degrade load_synth_yeast_plate() masks with colony-specific corruptions, then run the Spearman + argmax gate against the known Dice. Nothing else on this page reaches production until this lands.

  2. Add FFC as a fifth term

    Cheap, peer-reviewed, fully reference-free, and the only candidate orthogonal to all four existing terms. Note that SizeCV already approximates CSE's 1/(ln CSSD + 1), so that one is redundant.

  3. Persist the DINOSAM2 proposal scores

    detect/nn/_dinosam2_detector.py already computes cosine-to-prototype scores, uses them as an accept/reject gate, and discards them. Retaining an existing array is the cheapest win in the whole survey — no new algorithm.

  4. Drop RCA as an objective

    The near-perfect-mask collapse rules it out on its own; the reported ~11 min/case (approximate) and the annotated reference database it needs at inference are two further independent reasons. Keep it only in mind as an offline label generator to bootstrap a regressor.

  5. Leave one question open

    What is the cheapest colony-domain analogue of flow-error self-consistency for classical detectors, which emit no dense per-pixel field to disagree with? Three candidates, none catalogued: threshold stability under perturbation, agreement across the existing detector ensemble, or re-deriving a boundary field from the mask and comparing it against the enhance/_focus_edge_* response the pipeline already computes.
