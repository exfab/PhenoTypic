BacterSamPipeline

A new prefab in phenotypic.prefab that reproduces the detection and measurement pipeline of the latest bacterial growth-curve run, with colour correction and denoising left to an upstream step.

Source: the reference bacterial run Branch feat/bactersam-prefab off main@251e364fa 3 tasks

The run already skips colour and denoise

The run's pipeline has no colour-correction or denoising op. Its input stores came from a separate --mode process run, whose provenance journal records those three ops. So nothing is removed from the run. The prefab's docstring states that its input must already be corrected and denoised, and names the ops that do it.

Decisions

  • D1
    Drop the run's plot.

    The colony-over-time plot is bound to this experiment's own metadata columns, such as strain, salinity, pH and replicate. A prefab can't assume those columns exist, so plots=[].

  • D2
    Keep four texture measurers, one per scale.

    A single MeasureTexture(scale=[10,20,30,40]) gives the same columns, but writes one file instead of four in measurements_by_feature/. Then it would no longer match the run.

  • D3
    Crop defaults stay the run's values.

    They depend on the imager. The docstring says so.

  • D4
    8 × 12 grid by default, exposed as nrows / ncols.
  • D5
    SAM2 always reads detect_mat.

    The blur and background subtraction exist only to shape what SAM2 sees. A switch to rgb would quietly make both of them do nothing for detection, so it isn't a kwarg.

  • D6
    No colour or denoise op anywhere in the op tree, pinned by a test. The docstring points to --mode process --layer rgb with ColorCorrector / CalibrateColorRpcc and ColorDenoise.

What could still go wrong

  1. Running on a plain Image. KeepSectionLargest needs a grid, so preflight should refuse the run before any image is processed.
  2. Grayscale input. MeasureColor reads RGB, so preflight should say RGB is required.
  3. CLI staging. SAM2 sits at the top level and nothing is in a CPU-only slot, so the split must cut at Detector.
  4. JSON round trip. from_json must return a BacterSamPipeline with the same config.
  5. Kwargs that never reach their op. Each one is checked against its target field.
